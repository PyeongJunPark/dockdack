# DockDack

DockDack은 한국·미국 주식의 시세와 계좌를 조회하고, 여러 AI 모델의 신호를 독립적으로 관찰·관리하는 Windows 데스크톱 앱이다. 키움증권 REST API를 사용하며 모의투자가 기본이다. 화면에서는 관심종목, 보유종목, 주문·체결, 매매일지와 모델별 체결 성과를 한곳에서 확인할 수 있다.

현재 앱 버전은 **0.2**(패키지 `0.2.0`)다. 앱 버전과 `mark1.n prototype` 모델 번호는 서로 다른 체계다. 모델 선택, 감시 시작, 자동주문 허용도 서로 다른 조작이다. 앱을 켜거나 모델을 선택하는 것만으로 주문하지 않는다.

## 시작하기

Python 3.11 이상과 [uv](https://docs.astral.sh/uv/)가 필요하다. 저장소에서 다음 명령으로 GUI와 제공 모델의 추론 의존성을 설치한다.

```powershell
uv sync --locked --extra gui --extra prototype
```

프로젝트 루트의 [`.env.example`](.env.example)을 참고해 사용할 모의계좌 키를 `.env`에 설정한다. 키·토큰과 계좌 장부는 Git에 올리지 않는다. Windows에서는 `DockDack.vbs`를 더블클릭하거나 다음과 같이 실행한다.

```powershell
uv run --no-sync dockdack-gui
```

첫 화면은 모의 환경이며 감시와 자동주문은 **OFF**다. 잔고는 시작할 때 비동기로 조회한다. 보유종목 탭을 누르면 다시 조회를 요청하지만 시장별 최소 60초 간격이 적용된다. 처음 실행하거나 장부를 이관할 때는 [GUI 안내](docs/gui.md)와 [계정·설치 안내](docs/development.md)를 먼저 확인한다.

## 화면 구성

| 주탭 | 할 수 있는 일 |
| --- | --- |
| 관심종목 | 국내·미국 복합 순위 100종목의 시세, 선택한 모델별 판단, 현재가·전일 종가 대비 변화·일봉 차트를 본다. |
| 보유종목 | 시장별 잔고·매도가능수량·평가손익과 확인된 모델별 보유분의 예정 매도를 본다. 미국 보유금액은 표시용 KRW 전환이 가능하다. |
| 매매일지 | 시장 현지 날짜별 일·월·연 거래 기록을 본다. 미국 기록의 표시용 KRW 전환이 가능하다. |
| 주문·체결 | 앱 장부의 주문 상태와 확인된 체결, 원가·실현손익을 구분해서 본다. |
| AI 추론 모델 | `모델 선택`에서 모델을 각각 켜고 1회 매수 비중을 정한다. `모델 성과`에서 모델별 확인 체결에 근거한 실현손익을 본다. |
| 고급설정 | 시장·환경, 조회·감시, 공통 주문 상한·JSON 연결, 직접 신호기, 수동 규칙·구형 모델, 서버·감시 로그를 관리한다. |

상단 자동주문 상태를 눌러 ON/OFF를 전환한다. ON은 확인과 전체 조회 검증을 거친 뒤에만 실제 주문 허용 상태가 된다. OFF는 새 자동주문과 반복 감시를 중단하지만, 이미 접수된 주문을 취소하지는 않는다. 고급설정의 조회 전용 감시는 주문 허용과 별개다. 상단에는 자동주문 상태·최근 조회 요약·AI 모델 수가 나란히 보인다. 최근 조회는 중요한 판단 3개와 나머지 개수를 보여주며 전체 모델별 결과는 툴팁에서 확인한다. 모델 수는 **선택한 모델 수**이며 모두 추론에 성공했다는 뜻은 아니다.

## 모델과 주문의 경계

제공 `mark1.n prototype` 모델은 모의 전용이다. 장중 조회 모델은 완료 일봉 30개와 조회한 현재가를 사용하고, 장전 모델은 완료 일봉을 바탕으로 개장 전 후보를 동결한다. 기존 장중 장벽 모델의 추정확률, 새 일봉 대리모델의 점수와 장전 모델의 서로 다른 단위의 점수는 합산하지 않는다.

| 계열 | 모델 | 후보·청산 방식 |
| --- | --- | --- |
| 장중 장벽 | Mark1.0–1.2 | 추정확률이 기준을 넘으면 매수 후보를 낸다. 확인된 해당 모델 매수분에만 Mark1.0·1.2는 +1%/−0.9%, Mark1.1은 +0.5%/−0.4% 목표를 적용한다. |
| 장전 당일형 | Mark1.3–1.10 | 서로 다른 회귀·순위·비중·진화 모델이 다음 세션 후보를 낸다. 확인된 해당 모델 매수분에만 당일 마감 전 기간 매도 조건을 적용한다. |
| 장전 기간형 | Mark1.11–1.12 | 완료 30봉 기반 후보를 낸다. 확인된 해당 모델 매수분을 체결 관측일 기준 3·5번째 거래 세션 정규장 중에 각각 매도 시도한다. |
| 장중 조회용 일봉 대리모델 | Mark1.13–1.22 | 추세·반전·돌파·변동성·거래량 등 10개 다른 특징 가설을 국내/미국 각각 학습했다. 완료 30봉+현재가로 대리 점수를 계산하고 0.5 초과를 모의 매수 후보로 본다. 확인된 자기 매수분에만 +1%/−0.9% 기준을 적용한다. |
| 목표가·보유기간 일봉 대리모델 | Mark1.23–1.28 | 완료 일봉과 현재가로 목표가 도달 사건의 대리점수를 낸다. 확인된 자기 매수분은 모델별 +2–4% 목표가를 먼저 적용하고, 미도달 시 체결 관측일을 포함한 10·20번째 거래 세션 마감 5분 전부터 매도를 시도한다. 손절은 없다. |

Mark1.13–1.22의 정답은 다음 거래일 **관측 시가**에서 그날 전체 고가가 +1%에 닿고 저가가 −0.9%에 닿지 않은 사건이다. 실제 장중 진입 뒤의 경로나 목표·손절 선후를 학습·검증한 모델이 아니다. 두 번들에 20개 국내/미국 체크포인트가 봉인돼 있지만 점수는 검증된 장중 성공확률·수익률이 아니다. 입력·학습 영수증과 한계는 [장중 조회용 일봉 대리모델](docs/mark1-intraday-proxy.md)에, 다른 모델의 방식은 [현재 기능서](docs/FEATURES.md#ai-추론-모델)와 [연구 문서 모음](docs/mark1-5-research-roadmap.md)에 있다.

새 모의 설정에서는 Mark1.0–1.28이 모두 선택되지만 **감시·자동주문은 OFF**다. 계정에 저장된 모델 선택은 그대로 복원하고, 실전 환경에서 제공 prototype은 선택하지 않는다. Mark1.23–1.28의 학습 목표는 장중 임의 시점 이후의 체결 경로가 아니다. 목표 지정가 체결과 수익성도 검증되지 않았다. [목표가·보유기간 모델의 방법과 제한](docs/mark1-target-horizon-methods.md)을 확인해야 한다.

Mark1.4의 내부 장전 후보 점수는 기존 거래량 순위를 사용한다. 그 후보가 화면의 **복합 100종목**에 포함되지 않으면 실제 조회·신호·주문 경로에는 들어오지 않는다.

모델별 `1회 매수` 비중은 해당 모델 주문의 평가자산 기준 **상한**이다. 정수 주식 수, 실제 가용액, 시장별 주문당 수량·금액 상한과 모델 자체의 더 낮은 비중도 적용된다. 기본 10%는 권장 투자 비중이나 하루 누적 한도가 아니다.

모델은 각각 별도 프로세스에서 신호를 만들고, 주문 권한과 주문 직전 검사는 앱이 담당한다. 주문은 시세·정규장·보통주 적격성·잔고·미체결·신호 유효기간·중복 방지 검사를 모두 통과해야 전송된다. 주문 **접수는 체결이 아니며**, 모델별 매도는 확인된 자기 매수분에만 적용한다. 계좌 전체를 마감에 청산하는 기능은 없다. 모의 연결이나 테스트 통과는 수익성, 실제 체결 또는 실전 배포 승인이 아니다.

## 데이터·개발자 도구

일반 GUI와 별도로 다음 경로를 제공한다.

- `uv run dockdack`: 대화형 터미널에서 시세·잔고·주문을 조회하고, 명시적 확인을 거쳐 주문한다. [터미널 사용법](docs/terminal.md)
- `uv run dockdack quote AAPL`: 일회성 현재가 조회. 주문을 보내지 않는다.
- `uv run dockdack-maintenance --help`: 모의 장부 이관 및 감시 로그의 복구 가능한 보관. 기본 보관 작업은 dry-run이다. [개발·장부 안내](docs/development.md)
- `examples/`, `scripts/`, `dockdack-research`: 일봉 수집·정제, 모델 학습, 백테스트, 번들 내보내기와 진단. GUI의 자동 재학습 버튼이 아니다. [데이터 수집](docs/daily-dataset.md) · [정제](docs/dataset-cleaning.md) · [연구 도구](docs/research-tools.md)

별도 [목표가·보유기간 일봉 연구](docs/mark1-target-horizon-methods.md)는 완료 일봉과 조회가격으로 10/20/30봉·5/10/20거래일·목표 +2/3/4%를 비교한다. 이 가운데 Mark1.23–1.28의 국내·미국 가중치 12개를 봉인해 모의 화면의 모델 선택·독립 신호·보유분 매도 조건에 연결했다. 연결은 대리점수의 장중 정확도, 실제 체결 또는 수익성 검증을 뜻하지 않는다.

원본 일봉과 정제 데이터는 `data/`, 제공 모델 번들은 `models/`, 로컬 연구 결과는 `outputs/`에 둔다. 계정별 장부는 `.dockdack/` 아래에 저장된다. 모델 번들은 설치 wheel에 내장되지 않으며, 별도 파일과 출처·해시 검증이 필요하다. [JSON 신호 계약](docs/external-signals.md)은 사용자 추가 신호기를 연결할 때 참고한다.

## 검증과 제한

```powershell
uv run --no-sync python scripts/check.py
```

자동 테스트는 가짜 API 응답과 화면 밖 GUI를 주로 사용한다. 실계좌 주문·체결, 실제 브로커 운영 시간 전체, GPU 학습 재현 또는 수익성을 보증하지 않는다. 현재 구현 범위와 화면별 조건은 [기능서](docs/FEATURES.md), 실행·테스트 절차는 [개발 안내](docs/development.md), 변경 이력은 [DEVLOG](DEVLOG.md), 확인된 문제와 개선은 [2026-09-28 감사](docs/audits/2026-09-28/findings.md)에서 확인한다.
