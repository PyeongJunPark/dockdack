# LSTM30 demo checkpoints · 2026-09-15

국내 `domestic.pt`, 미국 `us.pt`는 기존 수집 DB로 RTX 5080에서 학습한 **모의투자 실험용** 가중치다. 각 파일은 약 814 KB이며 원본 학습 결과의 `best_model.pt`를 그대로 복사했다. 원본 DB·재개용 optimizer·계좌 정보는 포함하지 않는다.

| 항목 | 국내 | 미국 |
| --- | ---: | ---: |
| 학습 대상 종목 | 512 | 512 |
| 학습 윈도 | 867,456 | 750,082 |
| 검증 윈도 | 250,368 | 256,932 |
| 테스트 윈도 | 203,776 | 212,375 |
| 선택 epoch | 8 | 4 |
| 테스트 ROC AUC | 0.6328 | 0.6555 |
| 확률 0.5 이상 후보의 정답 비율 | 45.81% | 39.38% |

- 입력: 완료 일봉 30개, OHLCV. 2층 LSTM / hidden 128 / dropout 0.2, 학습 파라미터 202,369개.
- 정답: 다음 유효 관측봉 **종가**가 마지막 입력 종가보다 1% 이상 상승. 실시간 매수가 대비 수익 또는 장중 고가 터치를 예측하는 모델이 아니다.
- 기간: 2015년부터, 학습 2022년까지 / 검증 2023–2024년 / 테스트 2025년 이후. 종목 선택은 학습 구간 이력만 사용. 시장별 여러 종목을 묶어 한 모델을 학습했다.
- 실제 평균 매입가 대비 +1% 익절 / −0.8% 손절은 학습 목표가 아닌 별도 가격 규칙이다. 수수료·세금·슬리피지·주문 체결을 모델링한 수익 백테스트가 아니다.
- 매수 후보 정답 비율이 50% 미만이며 확률 보정·수익성을 검증하지 않았다. 테스트를 보고 임계값을 낮추지 않았다. 실전용으로 승인된 모델이 아니다.
- 재학습 방법, 데이터 필터 및 CUDA 종료 문제의 우회·재검증은 [전략 문서](../../docs/lstm30-strategy.md)를 참고한다.
