# mark_1 선정 체크포인트

2026-09-16 로컬 정제 DB 실험의 **연구용** 가중치다. 국내·미국 모두 `mlp_no_price_aug`가 2024년 선정 Brier 기준으로 뽑혔다. 다섯 증강 모델과의 [실측 비교](../../reports/mark1-20260916/REPORT.md), [학습/추론 규격](../../docs/mark1-strategy.md)을 확인한다.

| 파일 | 시장 | 파라미터 | SHA-256 |
|---|---|---:|---|
| `domestic.pt` | 국내 | 44,161 | `482462c064e77f8dc91ba201f5fa463e7d145d0fa184af222644b79ec3b58818` |
| `us.pt` | 미국 | 44,161 | `b6b28534c055dcab03e032106bb39296f5c4251bd0516593d87488d1a78265a7` |

두 파일 합계 약 365KB다. `metadata`에 모델 구조, 특징, 타깃, 2023년 독립 보정 계수, 원본 DB SHA-256, 선정 지표, 고정 매수 0.5·익절 1%·손절 0.9%와 한계를 넣었다. `Predictor`는 이를 검증하고 CPU에서도 읽는다. 원래 mark0 가중치는 변경하지 않았다.

최종 평가 시장별 60,000개에서 국내는 76신호·43.42% 성공, 미국은 1신호·실패다. **요구한 50% 초과 매수 신호의 신뢰성·수익성을 입증하지 못했다.** 모델을 선정했다는 것이 배포 적합 또는 자동매매 권장이라는 뜻은 아니다.

증강 모델 5종과 대조군의 전체 체크포인트·선정 고정 기록·예측은 `outputs/mark1/experiment-20260916/{domestic,us}`에 로컬 보존했다. 이 폴더는 Git 제외 대상이다. 최종 평가를 보고 더 좋아 보이는 모델로 바꾸지 않았다.

기본 연결은 [mark1 GUI](../../docs/MARK1_GUI.md)를 사용한다. 로드만으로 주문하지 않으며 감시/자동주문은 OFF다. 일봉 사건은 장중 진입 이후 실제 익절 확률과 같지 않다. 추가적인 분봉·체결 검증이 필요하다.
