# 모의 / 실전 환경 선택

기본은 모의투자다. 실전 경로는 가짜 HTTP 응답과 화면 밖 Qt 테스트로 검증했으며,
실제 계좌의 인증·주문·체결을 시험하지 않았다. 실전 선택은 실전 주문의 성공이나 수익을 보장하지 않는다.

## 화면에서 선택

트레이딩 데스크와 관심종목 대시보드 상단의 **모의투자 / 실전투자** 버튼을 사용한다.

- 실전 전환 전 실제 자금 사용·원금 손실·미체결 주문 유지에 대한 경고가 나온다. 기본 선택은 취소다.
- 대시보드 전환 요청은 먼저 감시와 자동주문·ON 예약을 중지한다. 경고를 취소해도 주문 OFF를 유지한다.
- 진행 중인 브로커 조회와 파일 검사가 끝난 다음 새 환경으로 전환한다. 이미 전송한 주문은 취소하지 않는다.
- 새 환경은 감시/자동주문 OFF다. 이전 모의 ON 예약이나 모의 실행기의 자동 시작 권한을 실전으로 넘기지 않는다.
- 잔고·시세·오류·신호 연결·주문 상한·실현손익 화면을 초기화하고 새 환경의 기록만 표시한다.
- 실전에서는 내장 랜덤 모의 신호기를 사용할 수 없다. 체크박스뿐 아니라 생성·수신·전송 직전에도 차단한다.

## 실전 설정

실전 서비스 가입·계좌 연결·App Key/Secret·허용 IP 등록이 먼저 필요하다.
[키움 공식 서비스 안내](https://openapi.kiwoom.com/intro/serviceInfo)를 확인한다.
키는 Git에서 제외된 `.env`에만 넣고 공개 문서나 로그에 붙이지 않는다.

```dotenv
DOCKDACK_KIWOOM_REAL_DOMESTIC_APP_KEY=
DOCKDACK_KIWOOM_REAL_DOMESTIC_SECRET_KEY=
DOCKDACK_KIWOOM_REAL_US_APP_KEY=
DOCKDACK_KIWOOM_REAL_US_SECRET_KEY=
DOCKDACK_ALLOW_LIVE_ORDERS=false
```

직접 실전 주문을 사용하기로 결정했을 때만 마지막 값을 `true`로 바꾼다. 앱이 이 값을 자동 변경하지 않는다.
키만 입력하거나 환경만 선택해도 자동주문이 켜지는 것은 아니다. 실전 키가 없으면 모의 키로 대체하지 않는다.
키/허용 설정 변경 후에는 앱을 재시작하고 실전을 다시 선택한다. 환경 버튼만 다시 눌러도 실행 중 프로세스의 환경변수가 갱신되는 것은 아니다.

- 수동 주문: 새 종목/시세 조회 → 주문 준비 → **실전** 최종 확인창의 종목·수량·가격 확인 → 한 번 전송.
- 자동 주문: 유효 규칙/외부 신호·수량·금액 상한 설정 → **실전 자동주문** 경고 확인 → 전체 조회 검증 → ON.
- 정규장, 신호 유효기간, 미체결/미확정 차단, 보통주 분류, 잔고/매도 가능 수량, 주문당 상한,
  최신 시세 검사와 API 속도 제한은 유지한다. 상한은 하루 누적 한도가 아니다.
- 국내 GUI 거래소는 KRX이며 NXT·예약·장외 주문을 새로 활성화하지 않는다. 미국 모의는 지정가만 허용한다.
- 새 환경에서 새로 준비한 주문만 전송하며, HTTP 호출 대기가 끝난 직전에도 환경·권한·중지 상태를 재확인한다.

## 기록 분리

- 기존 모의 데이터: `.dockdack/watchlist.sqlite3`를 그대로 유지한다.
- 실전 데이터: `.dockdack/real/<App Key 조합의 SHA-256 범위>/watchlist.sqlite3`.
- 실전 키가 아직 없으면 `real/unconfigured`의 준비용 목록만 사용한다. 주문은 차단된다.
- DB 자체에도 모드와 인증 범위를 기록한다. 기존 모의 DB를 실전 DB로 다시 지정하면 거절한다.
- 차트 캐시·관심종목·규칙·순위·신호·주문·체결·일지를 모두 같은 환경의 DB와 폴더로 묶는다.
- App Key 변경은 새 장부를 만든다. 같은 계좌인지 자동 추정하지 않으며 이전 장부는 보존된다.
  검증된 계좌 식별을 통한 장부 이관 기능은 아직 없다. 과거 매수 기록이 없는 매도의 손익은 미확인이다.

## 실전 외부 신호

실전 환경에서 내보낸 차트의 `export_id`와 전용 입력 경로를 사용하고,
외부 신호 파일 최상위에 **`"trading_mode": "real"`**을 반드시 넣는다.
`schema_version`, `source_id`, `signals` 등 기존 필드 규격은 [외부 신호 문서](external-signals.md)를 따른다.
모의 신호나 모드 표시가 없는 파일을 실전으로 재사용하지 않는다. 모의는 기존 모드 없는 파일도 호환한다.

실전 신호를 연결하고 자동주문을 켜면 조건에 맞는 신호를 개별 확인 없이 주문할 수 있다.
실제 계좌로 연결하기 전에 별도 모의 검증과 명시적인 사용자 판단이 필요하다.
