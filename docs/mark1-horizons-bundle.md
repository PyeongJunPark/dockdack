# Mark1.11·Mark1.12: E4 동결 점수의 기간 보유형

`models/mark1_horizons/`는 [E4 연구 결과](mark1-4-five-followups.md)의 국내·미국 100종목, 3개 동결 v2 시드와 3·5거래 세션 보유 비교에서 만든 별도 연구 묶음이다. 상세 원본 `report.json`은 Git 제외 로컬 `outputs/mark1/mark1-4-horizon-followup-auditfix-20260927/`에 있다. 새 가중치 학습은 **없다**. 시장마다 2018–2021 원래 훈련 적합도가 가장 높은 시드를 2022/2023–24 결과를 보지 않고 선택했으며, 두 시장 모두 시드 43이다. Mark1.11과 Mark1.12는 해당 시장에서 **같은 유전체·점수·진입 기준**을 사용하고 보유기간만 다르다. E4 원보고서는 사전 통과 기준을 만족한 승자를 **선정하지 않았다**. 따라서 이 두 번호는 원보고서의 승자가 아니라 사용자의 요청으로 뒤에 구성한 신규·사후 연구 모델이다.

| 모델 | 가상 진입 | 원래 백테스트 청산 | 원래 진입 간격 | 현재 모의 신호의 기간 매도 |
|---|---|---|---|---|
| Mark1.11 | 신호 다음 거래 세션 시가 | **매수 체결일을 1일째**로 세어 3번째 예정 거래 세션 **종가** | 3세션 간격, 중첩 없음 | 3번째 세션 **장중** 기간 매도 |
| Mark1.12 | 동일 | 5번째 예정 거래 세션 **종가** | 5세션 간격, 중첩 없음 | 5번째 세션 **장중** 기간 매도 |

현재 모의 연결의 장중 기간 매도는 원래 종가 가정과 다르고, 매일 후보를 평가·매수하면 원래 3/5세션 격자 진입보다 진입 빈도와 포지션 중첩도 달라진다. 따라서 위 백테스트 수익률을 현재 모의 전략의 예상 수익률로 표시해서는 안 된다. 기간은 매수 체결을 **관측한 세션을 1일째**로 삼아 거래일 캘린더로 계산하며, 3/5번째 세션이 시작되면 정규장 중 가격과 관계없이 자기 모델 lot만 매도 후보로 만든다. 단순 72/120시간 경과나 계좌 전체 장 종료 5분 전 청산으로 대체하지 않는다. 늦게 확인한 체결은 실제 체결시각보다 기간 시작이 늦어질 수 있다.

| 모델·시장 | 2022 개발 가상 순수익 (20bp 후) | 정수주 체결 | 2023–24 재사용 역사 |
|---|---:|---:|---:|
| 1.11 국내 | +0.35% | 3 | −0.14% (9건) |
| 1.12 국내 | 0.00% | 0 | −0.24% (4건) |
| 1.11 미국 | −2.58% | 16 | +4.08% (56건) |
| 1.12 미국 | −1.95% | 11 | +3.57% (36건) |

특히 국내 1.12는 2022년 거래가 **0건**이며 국내 1.11도 3건에 불과하다. 두 모델 모두 수익성 검증으로 볼 수 없고 `research_qualified=false`, `deployment_allowed=false`로 남긴다. 원보고서의 보유 중 일별 평가손익·낙폭은 계산되지 않았으며, 시장별 현재 카탈로그 생존편향·가상 개장/종가 체결·이미 본 2023–24 구간 한계가 있다.

## 추론과 검증

```python
from dockdack.mark1_horizons_inference import MarkHorizonPredictor

model = MarkHorizonPredictor("models/mark1_horizons", "domestic", "mark1.11")
rows = model.score_many(windows, [("005930", "KRX"), ("000660", "KRX")])
```

`windows`는 종목 순서와 일치하는 `[종목, 30, 5]` 완료 OHLCV 일봉이다. 호출자는 30개 봉의 날짜·완료 상태·현재 후보 전체를 따로 검증한다. 추론기는 계좌, 호가, 주문을 열지 않는다. `manifest.json`과 봉인 해시, 6개 원 챔피언의 SHA-256, 유전체 해시, 연구 점수 코드 해시를 확인한다. `tests/test_mark1_horizons_inference.py`는 실제 국내 92종목·미국 100종목 교차단면에서 RTX 5080으로 다시 계산한 원 소스 점수와 CPU 추론을 대조한다. 전 과거 후보 CPU↔GPU 최대 차이는 국내 0.000002623, 미국 0.000001192이며 원시 기준 반전은 둘 다 0건이다. 그보다 큰 ±0.000005/±0.000002 수치 경계 안은 `HOLD_NUMERIC_BOUNDARY`로 보류하고 원래 `score`와 `raw_above_frozen_threshold`를 별도 반환한다. 이 관측 폭은 미래 점수차의 보장이 아니다.

## 일반 GUI의 후속 모의 연결

Mark1.11과 Mark1.12는 **AI 추론 모델 → 모델 선택**에서 별도로 선택한다. 각 모델의 외부 작업자는 개장 10분 전 완료된 30봉·거래량 TOP100 묶음을 받아 해당 모델/시장에 동결된 점수·숫자 기준으로 매수 후보를 만든다. 장중 주문 판단은 모의 전용이며, 신호 연결이나 앱 실행만으로 감시·자동주문을 켜지 않는다. 실제 매수 주문을 보내려면 별도 ON 확인과 최신 시세·잔고·한도·미체결 검사가 필요하다. 확인된 자기 모델 매수 lot만 위 3/5세션 기한에 매도 후보로 삼으며 다른 모델·수동 보유분은 팔지 않는다. 이번 연결 작업에서 실제 계좌 주문·체결은 수행하지 않았다. 추론 번들의 `research_qualified=false`, `deployment_allowed=false`와 성과·체결 한계는 그대로다.
