# DockDack 모의투자 GUI

Windows 데스크톱용 PySide6 화면이다. 기존 브로커 함수를 사용하며 현재 버전은
**모의투자 전용**이다. `.env`에 실전 키나 `DOCKDACK_TRADING_MODE=real`이 있어도
GUI는 국내/미국 모의 키와 `https://mockapi.kiwoom.com`만 사용한다.

## 실행

첫 설치:

```powershell
uv sync --extra gui
```

이후 프로젝트 폴더의 `DockDack.vbs`를 더블클릭한다. 터미널 창 없이 GUI를 연다.
VBScript가 비활성화된 환경에서는 다음 명령으로 실행한다.

```powershell
uv run --extra gui dockdack-gui
```

`.env` 위치와 모의 키 설정은 [브로커 문서](kiwoom-broker.md)를 참고한다.
파일은 프로젝트 루트에서 읽으며 키나 토큰을 화면에 표시하지 않는다.

## 화면 사용

1. 왼쪽 삼성전자·SK하이닉스·애플·알파벳 A를 누르거나, 위 입력란에 코드/티커를 입력해 조회한다.
2. 미국 거래소는 자동 조회한다. 조회가 어려우면 검색 옆에서 NASDAQ/NYSE/AMEX를 선택한다.
3. 현재가와 전일대비가 표시된다. `15초 자동 조회`는 선택한 종목의 시세만 갱신한다.
4. 오른쪽 주문 유형·수량을 선택하고 매수 또는 매도를 누른다.
5. 최종 확인창의 종목·수량·단가·금액을 확인하고 전송한다. 돌아가기를 누르면 주문하지 않는다.
6. 계좌·주문 내역 조회 버튼으로 잔고, 선택 종목의 미체결 및 당일 주문·체결 내역을 확인한다.

주문 유형:

- **현재가 조회 → 지정가**: 주문 버튼을 누를 때 최신 현재가를 다시 조회하고 그 가격으로 주문을 준비한다.
  확인창에서 본 가격을 그대로 사용하며, 확인 뒤 가격을 자동 변경하지 않는다.
- **지정가 직접 입력**: 입력한 가격으로 주문한다. 국내는 정수 원, 미국은 달러 기준이다.
- **시장가 (국내)**: 단가를 정하지 않고 주문한다. 미국 모의투자는 지원하지 않아 전송 전에 안내한다.

현재가 지정가도 체결을 보장하지 않는다. 주문 접수 후 실제 체결 상태는 당일 주문·체결 탭에서 확인한다.
성공 코드나 주문번호가 빠진 응답은 **접수 여부 확인 필요**로 표시한다. 미접수로 단정하거나
자동 재주문하지 않으며, 수동으로 주문·체결 내역을 조회한 뒤 다음 행동을 결정해야 한다.
주문 접수 후 계좌/주문 내역을 한 번 갱신하며, 이후 상태는 조회 버튼으로 확인한다.
장 종료·주문 거절·응답 오류에 자동 재주문하지 않는다.
기존 주문 취소/정정 버튼은 이번 GUI에 포함하지 않았다.

API 요청 중에는 종목 변경과 주문 버튼이 잠기지만 창은 계속 반응한다.
종목 조회가 실패하면 기존 종목으로 잘못 주문하지 않도록 주문 버튼을 비활성화한다.
조회 오류는 하단과 활동 로그에 표시한다. 활동 로그는 현재 실행 중인 세션의 최근 200건이며
파일로 저장하지 않는다. 조회 내역은 API의 최대 10페이지 범위다.
요청 중 창 닫기는 응답이 돌아올 때까지 보류한다. 창을 닫아도 접수된 주문이 취소되지는 않는다.

## 테스트

```powershell
uv run --extra gui python -m unittest discover -s tests -v
```

테스트는 가짜 응답과 화면 밖 Qt 창을 사용하며 계좌에 주문을 보내지 않는다.
GUI 선택 의존성이 없으면 Qt 테스트는 건너뛰고 나머지 테스트는 실행한다.
