# Mark1.5–1.7 일봉 신경망 자동 비교 계약

작성: 2026-09-27. 이 묶음은 논문에서 **아이디어를 빌린 새 연구 실험**이며 논문 재현이나 실전 배포 모델이 아니다. 원 연구 실행 시에는 GUI·주문에 연결하지 않았다. 같은 날의 **후속 모의 전용 연결**에서 선택된 세 모델을 Mark1.5–1.7로 각각 동결해 신호 후보로 사용하지만, `research_only=true`, `deployment_allowed=false`와 아래 손실·검증 한계는 바꾸지 않는다. 모델 선택만으로 감시나 주문은 켜지지 않는다.

| 버전 | 입력·학습 | 출력 단위 | 참고한 연구 방향 |
|---|---|---|---|
| Mark1.5 | 완료된 30개 일봉 OHLCV의 창별 정규화 배열을 LSTM(선택적으로 GRU)에 입력; 비용 후 다음 날 시가→종가 순수익률을 Huber 손실로 학습 | **예상 순수익률, %** | Fischer·Krauss의 순환망 기반 주식 신호. 단, 그 논문의 롱숏 구조를 재현하지 않는다. |
| Mark1.6 | 같은 배열을 `30×5` 가격·거래량 타일로 놓아 작은 2D CNN으로 비용 후 양의 수익 여부를 분류 | **양의 순수익 가능성 추정, 0–1** | Sezer·Ozbayoglu와 Jiang·Kelly·Xiu의 이미지 표현. `15×15` 지표 영상이나 원 논문의 차트 렌더링을 재현하지 않는다. |
| Mark1.7 | 같은 날짜에 선택 가능한 종목의 30봉 배열을 자기주의로 함께 보고, 다음날 종목 간 순수익의 쌍별 순서를 학습 | **무단위 상대 순위 점수** | Feng 외의 상대 순위·종목 관계. 업종/기업 관계 그래프나 MASTER 구조를 재현하지 않는다. |

세 출력은 의미가 다르다. Mark1.6의 값은 sigmoid **확률 추정 점수**이며 별도 확률 보정·신뢰도 검증을 하지 않았으므로 검증된 실거래 승률이 아니다. Mark1.5의 %와 Mark1.7의 점수를 합산하지 않는다. Mark1.7은 같은 목표 거래일의 완료된 `t`까지 입력끼리만 상호작용한다. 하루 전체 종목 묶음이 없는 실시간 개별종목 추론에는 그대로 연결할 수 없다.

## 공통 비교

- 기존 `mark1_4_data.load_mark14_candidates`를 그대로 쓴다. 현존 카탈로그의 2017년 말 적격·거래대금 상위 100종목을 국내/미국 각각 고정한다. 매일의 실시간 거래량 TOP100이 아니다. 원본 DB를 읽기 전용으로 열고 데이터/WAL 전후 SHA-256을 비교한다. 별도 정제 DB의 `training_samples`는 **다음날 봉이 관측된 표본만** 들어 있어 후보 분모에 미래 관측 여부 선택편향이 생기므로, 현재 공정 비교에는 원본 DB에서 `t` 시점까지 품질검사한 후보 로더를 재사용한다. 원본 데이터와 정제 규칙은 수정하지 않는다.
- `t`까지 완료된 **연속 30거래일** OHLCV만 입력하고, `t+1` 시가·종가는 학습 정답과 평가 손익 계산에만 쓴다. 목표일 데이터가 결측이면 후보는 남기고 정답은 `NaN`; 훈련 정답만 제외한다. 평가에서 결측 선택은 정확 수익률을 미정으로 기록한다.
- 2018–2020 신경망 가중치 학습, 그 뒤 **30거래일 공백**을 두고 2021 보정, 2022 개발 비교, 다시 **30거래일 공백**을 두고 2023–2024 재사용 역사 진단이다. 세 시장별 시드 `41,42,43`과 고정 훈련 후보 선택률 `0.1/0.25/0.5/1/2/5%`를 2021 정확 경로에서만 골라 숫자 점수 기준을 동결한다. 입력 스케일러와 수익률 극단값 경계는 관측된 훈련 표본에서만 계산한다.
- 동일한 평가기는 다음 거래일 **시가 매수→당일 종가 매도 가정**, 시작 총자산의 종목당 최대 10%, 최대 10종목, 정수주, 현금 한도, 레버리지 없음, 왕복 비용 20bp를 사용한다. 비용 민감도는 0/20/40bp. 결측 선택을 0원 손익이나 유리한 체결로 바꾸지 않는다. 주문 가능성이나 실제 개·폐장 체결은 미검증이다.
- 2022 및 2023–2024 구간은 선행 Mark1 연구에서 이미 확인했다. 따라서 성적이 좋아도 **새 블라인드 시험이나 수익 보증이 아니다**. 여러 버전·시드·후보 기준 중 유리한 것을 과거 평가로 다시 고르면 그 자체가 데이터 스누핑이다. 시점별 상장폐지 포함 종목목록, 기업행사 당시 가용 가격, 실제 체결비용, 앞으로 쌓일 미사용 paper 기간이 필요하다.

## 실행·저장

작업 폴더에서 새 경로를 지정한다. 아래 명령은 기본적으로 양 시장×세 모델×세 시드를 **CUDA 필수**로 실행한다. CUDA가 없으면 CPU로 조용히 전환하지 않고 시작 전에 중단한다. 연구 함수를 직접 호출해도 기본 장치는 `cuda`이며 `auto`나 일반 `cpu` 학습은 거부한다. 작은 합성 단위시험에서만 `device="cpu", test_only_allow_cpu=True`를 명시해 예외를 사용하며, 이 실행은 본실험 성과가 아니다. 초기 기본값 5 epoch/숨김폭 32는 실행을 제한한 출발점이며, 긴 학습은 별도 **새 출력 폴더**에서 `--epochs`와 `--hidden`을 명시해 반복한다. 이전 결과 파일은 덮어쓰지 않는다.

```powershell
& '.venv-ml-cuda/Scripts/python.exe' -m examples.research_mark1_series --device cuda --output-dir outputs/mark1/mark1-series-new-run
```

각 시드마다 `*-model.json`, `*-weights.npz`, `*-scores.npz`가 생긴다. 시장·버전별 `*-report.json`에는 훈련/보정/개발/재사용 역사 기간의 0/20/40bp 경로, 선택된 기준·시드, 신호 수·정수주 체결 수·최대낙폭·결측 여부가 들어간다. **모든 보고서가 완료되면** `manifest.json`을 마지막에 쓴다. 중단된 폴더는 성공 산출물이 아니며 검사 또는 보존 후 새 출력 경로에서 다시 실행해야 한다.

성능 비교 시 현금 0%, 기존 Mark1.4 E1/E5 동결 결과, 같은 날짜/비용/투자비중의 단순 규칙을 함께 본다. 다른 논문의 수익률 숫자 또는 백테스트의 신호율만으로 수익성·실전 배포 자격을 인정하지 않는다. 후속 모의 연결은 사용자가 요청한 별도 실험이며 원 연구의 성과 합격을 뜻하지 않는다.

## 2026-09-27 첫 실행 결과

`outputs/mark1/mark1-series-100x2-contractfix-20260927/manifest.json`에 완료 보고서 6개, 가중치/점수 파일 18쌍을 저장했다. Windows/Python 3.13.5, NumPy 2.5.3, PyTorch **2.11.0+cu128**, NVIDIA GeForce **RTX 5080**에서 모든 본실험 학습을 `cuda`로 실행했다. 양 시장 각각 100종목, 국내 154,216개·미국 172,680개 후보, 각 모델 시드 41·42·43, 5 epoch, 숨김폭 32였다. 전체 완료 63.127초에는 DB 적재·지문 재검사·결과 기록이 포함된다. 2018–2020 학습, 2021 보정, 2022 개발, 2023–2024 재사용 역사 기간과 30세션 공백을 그대로 썼다.

아래는 동결된 시드/숫자 점수 기준의 **가상 시가→종가 매매·왕복 20bp 후** 정확한 포트폴리오 경로다. 괄호는 정수주 체결 수다.

2022년 **여섯 시장×방법 모두 비용 후 손실**이다. 같은 고정 100종목·회계 계약의 Mark1.4 E5 국내 +5.43%, E1 미국 +2.88% 개발 수치보다 낮고, 현금 0%에도 모두 못 미친다. Mark1.5 국내 2023–24의 양의 수치는 이미 여러 번 본 역사이며, 2022 손실이나 재현성 문제를 해결하지 않는다. Mark1.6 국내 2023–24는 선택 목표일의 결과가 없어 정확 경로가 미정이다. **원 연구 단계에서는** 세 방법 모두 GUI·자동주문에 승격하지 않았다.

첫 본실험 시도는 국내 보고서 3개 생성 후 미국 첫 가중치 파일에서 **시장 접두사 누락에 따른 파일명 충돌**로 중단했다. 원본/기존 파일을 덮어쓰지 않았고 그 불완전 산출물은 `outputs/mark1/mark1-series-100x2-20260927/`에 남아 있다. 파일명에 시장을 포함하도록 고친 뒤 위 `contractfix` 새 폴더에서 18개 적합을 처음부터 재실행해 완료했다. 이보다 앞서 실행 경로 검사용 5종목 CPU 작은 점검과 국내 100종목 Mark1.7 CUDA 1 epoch 점검은 위 본실험 성적·시간·시드 수에 합산하지 않았다.

## 2026-09-27 후속 모의 신호 연결

원본 학습 결과를 재학습하거나 유리한 시드를 사후 변경하지 않고 [해시 검증 번들](mark1-series-bundle.md)로 고정했다. 현재 일반 GUI의 **AI 추론 모델 → 모델 선택**에서 Mark1.5 LSTM, Mark1.6 CNN, Mark1.7 같은 날 종목 attention을 각각 체크할 수 있다. 선택된 모델은 완료 30봉·해당 시장 TOP100의 장전 묶음으로 독립 모의 매수 후보를 내고, 확인된 자기 매수 lot만 당일 정규장 마감 5분 전부터 가격 무관 매도 후보가 된다. 실제 주문은 별도의 감시·모의 자동주문 ON, 최신 시세·잔고·한도·미체결 검사를 통과해야 하며 시가·종가 체결을 보장하지 않는다. 점수 단위가 달라 장중 Mark1.0–1.2의 확률 평균이나 다른 장전 점수와 섞지 않는다. 2022년 손실, 현재 카탈로그 생존편향, 이미 본 역사, 실제 비용·체결 경로 미확인이라는 연구 한계는 그대로다.
