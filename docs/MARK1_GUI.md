# mark1 GUI 연결과 매매 조건

mark1은 기존 DOCKDACK 모의 실행기의 차트 조회, 보유 수량 확인, 외부 신호 수신, 주문 안전 검사를 재사용한다. 별도 화면에 그림만 표시하는 모형이 아니라 실제 신호 수신 경로에 연결되어 있다. **실행 직후에는 감시 중지, 자동주문 OFF**이며 이 작업에서 계좌 연결이나 자동매매를 실행하지 않았다.

**연구용 모델이며 50% 초과 신호의 성능·수익성은 입증되지 않았다.** 보정 확률이 50%를 넘는다고 실제 성공률도 50%를 넘거나 수익이 난다는 뜻은 아니다. 화면에서도 이 경고를 상시 표시한다. 구체적인 모델별 검증 결과는 별도 실험 보고서를 확인한다.

## 실행

`mark_1` 작업 폴더에서 아래처럼 실행한다. 체크포인트는 먼저 학습을 끝내 만들어져 있어야 한다.

```powershell
cd C:\Users\user\Desktop\dockdack-mark_1
& C:\Users\user\Desktop\dockdack\.venv\Scripts\python.exe -m examples.run_mark1_gui
```

기본 체크포인트는 `models/mark1/domestic.pt`, `models/mark1/us.pt`, 기본 관심종목은 삼성전자와 AAPL이다. `--symbol domestic:KRX:005930`처럼 시장을 한정하면 해당 시장 체크포인트만 읽는다. 경로는 `--domestic-checkpoint`, `--us-checkpoint`로 지정할 수 있다. `--top-domestic100`과 `--top-us100`은 해당 시장의 기존 보통주 거래대금 TOP100 감시 기능을 연결하는 선택 사항이다.

이 실행기는 `--arm`을 제공하지 않으며 창을 연다고 조회나 주문을 시작하지 않는다. GUI에서 감시 또는 자동주문을 별도로 시작해야 한다. 실제 시세/잔고 조회는 사용자가 감시·조회 기능을 실행한 뒤 이루어지고, 자동주문은 추가 확인과 검증을 통과해야 한다. 실전투자는 허용하지 않는다.

기존 mark0 장부와 혼합하지 않는다.

- 전용 실행 폴더: `.dockdack/mark1-demo`
- 전략 식별자: `mark1`
- 외부 신호 출처: `mark1-daily-barrier`
- `strategy.json`으로 다른 전략의 기존 실행 폴더 재사용을 차단한다.
- 일반 주문의 기본 상한은 기존과 같이 1주, 국내 50만 원/미국 1,000달러다. 매도도 실제 보유·매도가능 수량과 상한을 넘지 않는다. 이 실행기는 계좌 전체 마감 청산을 자동 설정하지 않는다.

## 31개 입력의 정확한 의미

GUI는 최소 **31개 일봉을 요청**한다. 오늘 진행 중인 봉이 있으면 이를 제외하고, 가장 최근 **30개 완료 거래일의 OHLCV**를 선택한다. 오늘 봉이 없으면 완료 봉 중 최근 30개를 사용한다. 거래일 달력상 날짜가 빠지거나 마지막 완료 봉이 오래되면 매수를 보류한다.

모델에는 이 30개 완료 봉과 **현재가를 묻는 토큰 1개**, 총 31개 토큰이 들어간다. 31번째 봉의 최종 고가·저가·종가·거래량을 미리 아는 것처럼 넣지 않는다. 마지막 가격 변형은 학습용 가상 진입가 질의이며, 독립된 실제 거래일이 늘어났다는 뜻이 아니다.

학습 성공 사건은 다음과 같다.

```text
해당 거래일의 고가 >= 진입 기준가 × 1.01
그리고 해당 거래일의 저가 > 진입 기준가 × 0.991
```

일봉만으로 두 경계를 건드린 순서나 장중 현재 시점 이후의 경로를 알 수 없다. 따라서 익절·손절 경계를 모두 건드린 날은 보수적으로 실패다. **GUI 확률은 일봉 전체 구간의 보수적 사건을 추정한 값이며, 임의의 장중 진입 시점 이후의 실제 익절 확률로 검증된 값이 아니다.** 시가 기준으로 검증한 모델에 장중 현재가를 질의하는 것에는 시점·분포 차이가 남는다. 이 한계는 화면에도 표시된다.

## 매수·매도 규칙과 화면

| 상황 | 판단 |
|---|---|
| 미보유, 보정 성공확률 > 50% | 매수 신호 |
| 미보유, 확률이 정확히 50% 또는 그 이하 | 대기 |
| 보유, 현재가 >= 실제 평균 매수가 × 1.01 | 익절 매도 신호 |
| 보유, 현재가 <= 실제 평균 매수가 × 0.991 | 손절 매도 신호 |
| 보유, 두 가격 경계 사이 | 대기. 모델 확률만으로 매도하거나 추가 매수하지 않음 |

상단 설명과 `mark1 모델 · 매매 조건` 탭에서 조건, 종목별 모델명, 보정 성공확률, 전달된 BUY/SELL/HOLD, 판단 사유를 확인한다. 신호가 나왔다는 것과 주문 접수·체결은 서로 다르다. 자동주문 OFF 상태에서도 감시를 실행하면 신호 수신을 확인할 수 있다.

`+1% / -0.9%`는 수수료·세금 미반영 평균 매수가 기준이다. 조회 주기, 갭, 호가, 슬리피지, 미체결 때문에 실제 손익이 이 숫자에 정확히 고정되지 않는다.

### 현재가 재검증

가격에 따라 성공확률이 변하므로, 오래된 매수 신호를 새로운 가격에 그대로 적용하지 않는다. mark1 전용 엔진은 기존 주문 사전 검사에서 재조회한 현재가로 확률을 다시 계산한다. 호가 단위 보정으로 지정가가 달라지면 그 지정가에서도 `p > 0.5`여야 한다. 전송 직전의 지연 처리 후에도 모델·시세 수명·최신 신호·정지/OFF·기존 안전 검사를 다시 확인한다. 모델 또는 연속 30봉이 없거나 확률이 50% 이하이면 전송하지 않는다.

최종 전송 검사에서는 HTTP 호출 중 추가 브로커 조회를 하지 않고 가장 최근 사전 검사 시세를 사용한다. 그 시세는 최대 15초 이내여야 한다. 검사와 실제 체결 사이에 가격이 움직일 수 있으며, 지정가도 체결을 보장하지 않는다. 매도는 기존 엔진이 최신 보유 평균가와 최신 조회 가격으로 익절/손절 조건을 재검증한다.

## 파이썬 모듈 API

모델 추론 자체는 주문하거나 감시를 시작하지 않는다.

```python
from dockdack.mark1_inference import Predictor
from dockdack.mark1_adapter import decide_position

model = Predictor("models/mark1/domestic.pt", device="cpu")
# bars: 오래된 순서대로 완료된 30개 [open, high, low, close, volume]
prediction = model.predict(bars, current_price=70000)
decision = decide_position(
    current_price=70000,
    quantity=0,
    sellable_quantity=0,
    prediction=prediction,
)
```

예측 반환값의 핵심은 `probability_success`, `predicts_success`, `buy_threshold=0.5`다. 보유 시에는 `quantity`, `sellable_quantity`, `average_price`를 넣으면 모델 없이도 익절/손절 판단이 가능하다.

`Mark1SignalProducer`는 기존 버전 1 차트 JSON을 받아 `payload, diagnostics`를 반환한다. 생성 시 시장별 `predictors`, 신원을 확인할 수 있는 `position_provider`, 명시적인 `quantity`, `max_krw`, `max_usd`가 필요하다. 전용 `state_path`를 유지해 같은 차트 내보내기의 판단을 불변으로 보존한다. 다른 전략의 상태 파일을 재사용하지 않는다. 매도 신호는 기존 계약의 `cost_profit_pct="1"` 또는 `cost_loss_pct="0.9"`로 전달된다.

```powershell
& C:\Users\user\Desktop\dockdack\.venv\Scripts\python.exe -m examples.preview_mark1_gui
```

이는 소스 저장소의 테스트용 가짜 서비스·가짜 모델만 사용한다. 네트워크를 금지하고 화면은 오프스크린으로 렌더링한다. 실제 모델 성능이나 실제 계좌 화면이 아니며, 결과 이미지에도 가상 데이터임을 표시한다. 출력은 `outputs/mark1/gui-preview.png`다. 임시 실행 장부는 작업이 끝나면 정리되며 기존 자동매매 폴더에는 접근하지 않는다.
