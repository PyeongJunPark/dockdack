# Mark1.4: 무작위 신경 매수규칙의 진화 연구

작성: 2026-09-27. 이 문서는 결과를 보기 전에 정한 **연구 계약**이다. Mark1.2·Mark1.3 모델, GUI, 자동주문, 운영 장부와 분리한다. 실제 주문 신호가 아니며 `research_only=true`, `deployment_allowed=false`를 유지한다.

## 질문과 방법

완료된 과거 30개 일봉의 OHLCV를 받아 종목별 매수 우선순위 점수를 내는 작은 비선형 신경망을 무작위로 생성한다. 사람이 이동평균 교차와 같은 매수 공식을 사전에 적지 않는다. 개체는 **종목이 아니라 점수망의 가중치와 진입 기준**이다. 무작위 개체들을 같은 역사 시장에서 평가해 훈련구간 성적에 따라 선택·교배·돌연변이시키고 여러 세대 반복한다. 초기값·시드·생성한 후보 수·실패한 후보까지 기록한다. 유전 알고리즘을 매매규칙 발견에 적용한 [Allen·Karjalainen 연구](https://rodneywhitecenter.wharton.upenn.edu/wp-content/uploads/2014/04/9320.pdf)는 방법론적 선례이지 이 주식·기간의 수익 보증이 아니다.

Mark1.3과 다른 점은 8개 수작업 요약특징에 MLP를 지도학습하는 대신 **30×5 봉 배열에서 무작위 신경망의 판단 자체를 진화**시키는 것이다. 데이터 품질·시각·체결 한계는 사라지지 않는다. 5080 GPU는 대량 개체 점수 계산을 가속하는 용도로 사용할 수 있지만 GPU 시간만 늘려 승률을 입증할 수는 없다.

## 결과를 보기 전 고정한 시각·자본 계약

1. 국내·미국 시장을 분리한다. 원본 SQLite는 읽기 전용으로 열고 현존 종목목록이라는 생존편향을 명시한다. 처음 100종목은 2017년 말까지 확인 가능한 과거 품질·유동성으로 한 번 선택한다. 이는 역사 매일의 거래량 TOP100이 아니며, 향후 시점별 상장폐지 자료로 바꿔야 할 한계다.
2. 거래일 `t`의 **완료된** 30봉만 입력한다. `t+1` 시가·고가·저가·종가·거래량은 종목 선택·점수·진입 기준에 사용하지 않는다. `t+1` 시가에 매수, 같은 날 종가에 매도했다고 가정한 결과는 나중에 평가할 때만 읽는다. 그 두 가격에 실제 주문이 체결된다는 뜻은 아니다.
3. 거래일 시작의 총자산에서 각 매수에 최대 **10%**를 할당한다. 한 시장에서 동시에 최대 10종목, 현금 한도 내·레버리지 없음이다. 종목별 신호가 10개를 넘으면 진입 기준을 통과한 점수 순서로 제한하며, 기대에 못 미치면 현금을 남긴다. 다음 날 재투자에는 전일 청산 후의 자산만 쓴다. 거래비용을 차감한 종가 청산 가정으로 일별 총자산을 복리 계산한다. 정수주·미체결·거래정지의 처리 여부는 실행 보고서에 명시한다.
4. 기본 왕복 비용은 **20bp**, 같은 동결 신호의 민감도는 0/10/20/40/80bp로 본다. 이 값은 실제 수수료·세금·스프레드·시장충격의 측정치가 아니다. 결과가 없는 다음 날 봉을 정확한 수익 0 또는 유리한 체결로 바꾸지 않고 후보/미관측 건수를 분리한다. 해당 종목을 선택하면 **정확한** 총자산·수익률은 미정으로 표시한다. 참고용으로만 미관측 주문이 전혀 체결되지 않은 시나리오와 배정 자금 전액 손실 시나리오를 병기하며, 어느 쪽도 관측된 실적이나 엄밀한 상·하한이라고 주장하지 않는다.

## 진화·검증 계약

- 2017년은 종목 사전선정, 2018–2021년은 개체 진화, 2022년은 동결한 개체의 개발 검증, 2023–2024년은 **이미 다른 Mark1 연구에서 본 역사**의 참고 평가로 구분한다. 학습·검증·평가 사이에는 적어도 30거래일의 공백을 둔다. 평가 결과를 본 뒤 유리한 세대·시드·임계값을 다시 고르면 해당 평가는 새 검증이 아니다.
- 개체의 적합도는 **비용 후 포트폴리오 성과**로 계산한다. 총수익만이 아니라 최대낙폭, 거래 횟수, 거래일별 분산, 무거래·항상매수·단순 모멘텀과의 차이를 함께 공개한다. 거래를 강제해 빈도만 높이지 않고, 미체결/결측을 낙관적인 수익으로 처리하지 않는다.
- 실제 체결수량이 0인 규칙은 수익 있는 규칙으로 채택하지 않는다. 훈련 구간 미관측 종목을 매수한 규칙은 정확한 적합도에서 제외한다. 가능하면 훈련 구간 **실행 거래일 2% 이상**인 최선의 개체도 별도 참고 후보로 보관한다. 이 후보는 훈련 결과만으로 정하며 검증·평가 결과를 보고 바꾸지 않는다. 활성 후보가 없거나 비용 후 손실이면 그대로 기록한다.
- 비교할 세대 수·개체 수·시드 수를 모두 보고한다. 유전탐색은 반복 백테스트이므로 최고의 역사 결과가 우연일 수 있다. [백테스트 과적합 확률 연구](https://scholarworks.wmich.edu/math_pubs/42/)와 [다중 탐색의 성과 과대평가 연구](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)를 근거로, 후보 총수와 실패 실험을 숨기지 않고 별도 미래 paper 기간을 최종 관문으로 둔다.
- 국내와 미국은 각각 신호일·체결 가정 건수·총자산 경로·비용 후 수익·최대낙폭·비용 민감도를 보고한다. 한 시장의 작은 양의 결과를 다른 시장 또는 실거래로 이전하지 않는다. 특히 2023–2024 평가는 이미 사용된 역사라 독립 최종 시험이 아니다.

첫 본실험의 사전 고정 설정은 **시장별 100종목, 개체 64개×50세대×3개 독립 시드(41·42·43), 왕복 20bp**다. 구현 오류를 잡기 위한 소규모 기능 확인은 본실험과 구분해 기록한다. 계산 자원/시간 문제로 이 설정을 줄이거나 중단하면 이유와 완료한 탐색 수를 남긴다. 본실험 중 검증·과거 평가 결과를 보고 세대/시드·신호 기준을 다시 선택하지 않는다.

### 별도 2차 탐색 계약: 희소 신호 탐색 공간

첫 탐색의 **학습 구간**에서 초기 절대 점수 기준 `[-0.4,0.4]`과 마지막 `tanh`가 많은 개체를 매일 10종목 매수로 몰아넣는 문제를 보았다. 첫 여섯 실행은 원래 설정으로 완료·보존하고, 이후 별도 `v2` 탐색을 한다. 이 변경은 이미 본 평가 구간을 새 미사용 시험으로 만드는 것이 아니며, `v1` 결과를 덮어쓰지 않는다.

- 마지막 출력은 선형 점수로 바꾸고 유전자는 **목표 학습 후보 선택률**의 로그값을 가진다. 초기 64개체를 `0.1%, 0.25%, 0.5%, 1%, 2%, 5%, 10%, 20%` 선택률에 고르게 배치하고 그 범위 내에서 교배·변이한다. 각 개체의 숫자 점수 기준은 **2018–2021 학습 특징과 해당 개체 점수만**으로 한 번 계산한다. 선택된 개체의 숫자 기준을 동결해 2022 및 2023–2024에 그대로 적용하며, 평가 구간 점수분포에 맞춰 다시 조절하지 않는다.
- 현금 보유 수익 0을 비교 기준으로 둔다. 학습에서 실제 거래일 20일 이상·정수주 체결 50건 이상이고, 결측 선택이 없어 정확한 경로가 계산되는 후보만 활성 후보로 인정한다. 학습에서 현금 기준을 넘지 못하면 ‘비용 후 유리한 규칙 미발견’으로 표시하고 손실 규칙을 추천하지 않는다. 거래 건수 기준을 낮춰 평가 결과에 맞추지 않는다.
- `v2`도 시장별 100종목·64개체×50세대×시드 41/42/43·왕복 20bp·10%×최대10종목·30거래일 공백을 유지한다. 전체 후보/실패와 무거래·항상매수·5일 모멘텀 기준을 기록한다. 2022·2023–2024의 숫자는 **탐색 공간 수정이 첫 결과를 본 뒤 이루어진 재사용 역사 진단**으로 표시한다. 실제 신규 미래 구간 없이는 성과 승격을 금지한다.

## 승격 불가 조건

연구용 모델이 과거 표본에서 우수해도 이 문서만으로 GUI 표시·모의/실전 자동주문에 연결하지 않는다. 현재 카탈로그의 상장폐지 누락, 과거 기업행사 수정과 데이터 이용 가능 시각, 개·폐장 실제 체결/수량/가격, 세금·환전, 별도 미사용 장래 구간을 확인하기 전에는 `deployment_allowed=false`다. 매매 빈도가 높아지는 것과 비용 후 기대수익이 양수인 것은 서로 다른 결과다.

## 실행 기록

### 1차 탐색 `v1`: 완료

2026-09-27 RTX 5080 / PyTorch 2.11.0+cu128 / NumPy 2.5.3에서, 국내·미국 각각 **100종목×시드 41·42·43×64개체×50세대**를 실행했다. 총 **19,200개체 평가**이며 시드별 3,200회다. 2017년 말 선정 적격은 국내 693종목·미국 1,983종목, 그중 100개씩 고정했다. 학습 후보는 국내 92,680건·미국 98,700건, 검증 18,581/22,100건, 과거 평가 37,740/45,880건이다. 2018–2021 학습, 2022 검증, 이미 본 2023–2024 평가에 30거래일 공백을 적용했다. 원본 DB는 읽기 전용이며 수집 중 변경 여부 해시를 각 실행에서 확인했다.

**판정: 승격 불가.** 두 시장의 계산 가능한 평가 다섯 결과는 현금 0% 미만이고, 국내 43 한 결과는 미정이다. 국내 41·미국 42/43의 양의 학습 수익이 평가에서 사라졌고, 상당수 개체는 매일 10종목을 채워 비용에 잠식됐다. 이를 근거로 아래의 별도 희소 신호 탐색을 연구용으로 실행한다. 2023–2024는 이미 본 역사이며, 현재 종목 카탈로그의 생존편향·사후 수정주가·개폐장 체결과 비용 불확실성은 해결되지 않았다. 모의/실전 주문과 GUI는 사용하지 않았다.

### 2차 탐색 `v2`: 완료

동일한 RTX 5080, 원본/기간/종목·왕복 20bp, 시드 41·42·43, 64개체×50세대를 국내·미국 각각 실행했다. `v2`도 **19,200개체 평가**이며 처음 64개체는 목표 학습 후보 선택률 8개 구간에 각 8개씩 넣었다. 학습 후보 점수만으로 숫자 기준을 정하고 동결했으며, 검증·과거 평가의 점수나 정답으로 다시 조절하지 않았다. 최소 **학습 거래일 20일·정수주 체결 50건**, 정확한 학습 경로와 양의 비용 후 학습 총수익/적합도를 모두 만족한 후보가 여섯 실행에서 나왔다. 이것은 **학습에만 합격**한 뜻이지 검증/실전 승인이나 성공확률이 아니다.

선택한 `v2` 평가 신호에는 결측 목표일 가격이 없어 위 복리 수익률은 모두 계산 가능했다. 왕복 비용 0bp에서도 국내 41/43·미국 42는 손실이고, 국내 42 +0.30%, 미국 41 +0.12%, 미국 43 +2.20%만 양수였다. **20bp에서는 여섯 실행 전부 손실**이다. 비용 0/10/20/40/80bp 전체 결과는 각 실행 `report.json`의 `frozen_test_cost_sensitivity_bps`에 있다. 목표 학습 선택률이 0.1%대에 몰려 신호가 드물며, 1차의 매일 매수 쏠림을 해결한 대신 빈도와 실전 수익성을 함께 확보하지 못했다.

산출물은 로컬 Git 제외 `outputs/mark1/mark1-4-v2-{domestic|us}-seed{41|42|43}-20260927/`에 `report.json`, `champion.json`, `champion.npz`로 보관했다. `champion`은 **학습 전용 조건을 통과한 연구 후보**라는 뜻이며 GUI·주문에 연결하거나 실전 승인한 모델이 아니다. `report.json`에는 학습 수치 기준의 고정값과 출처, 실패한 개체를 포함한 탐색 건수, 재사용 역사 평가, 비교 기준, 결측 시나리오, 원본 해시와 GPU·환경을 기록했다. `v1` 산출물을 덮어쓰지 않았다.

합계 **12회·38,400개체 평가**, GPU 점수 계산과 CPU 포트폴리오 평가를 포함한 진화·평가 경과시간의 합계 **1,208.06초**, 후보 적재 **137.03초**였다. 기능 검사와 작은 GPU 예비 실행은 이 횟수에 합산하지 않는다. Mark1.4 집중 테스트 **15/15**, 별개 Mark1.3 회귀 **3/3**, 문법·Git 공백 검사에 성공했다. 모든 본실험에서 원본 DB 사전/사후 지문이 일치했다. GUI·자동매매·모의/실전 주문, 운영 DB 수정·커밋·푸시는 수행하지 않았다.

**최종 판정: 두 탐색 모두 연구용·배포 불가.** 사전 고정한 20bp 조건에서 정확한 평가가 가능한 **11회 모두 현금 0% 미만**이고 나머지 1회는 결측으로 미정이다. 더 많은 세대를 같은 기간에 반복하면 우연한 학습 승자를 고를 가능성이 커진다. 2026년 현재 목록 기반의 생존편향, 상장폐지·기업행사 당시 데이터 가용성, 개장/종가 실제 체결·스프레드·세금·시장충격, 독립적인 장래 paper 기간이 남아 있다. 새 데이터와 시점별 종목목록/체결 검증 없이 이 모델을 매수 트리거로 승격하지 않는다.
