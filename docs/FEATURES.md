# DockDack 기능 목록

기준일: **2026-09-25** · 앱 **0.1 (MK1)** · `6e3ace7` 이후 감사 개선·GUI 정리·모델별 체결 성과·선택형 Mark1.2 모의 신호 · 개발 브랜치: `mark_1`

이 문서는 **앱과 저장소가 현재 제공하는 기능을 하나씩 정리한 목록**이다. 감사 지적 후 구현된 변경을 반영했다. 기능 존재와 실제 계좌 체결 검증은 다르다. [최초 감사](audits/2026-09-24/README.md)는 당시 증거이며, 현재 수정 상태는 [개선 결과](audits/2026-09-24/remediation.md)를 본다. [GUI 256항목](audits/2026-09-24/controls.md)은 개선 전 목록이다.

## 먼저 구분할 것

- **앱 버전:** 화면에는 `0.1 (MK1)`, 설치 패키지에는 `0.1.0`으로 표시한다. prototype 모델 이름·가중치·매매 조건을 바꾸는 버전 변경이 아니다.
- **일반 화면:** `DockDack.vbs`로 여는 현재 통합 데스크. 기본은 모의 환경, 감시·자동주문 OFF이며 기존 MK1·MK1.1 외부 prototype 두 개만 선택한 상태다. MK1.2는 기본 해제이며 사용자가 명시적으로 선택할 수 있다. 모델 선택만으로 주문하지 않는다.
- **고급/호환 기능:** 일반 설정에 남은 과거 트리거, 별도 수동 주문 창, 구형 전용 실행기. 기본 화면과 실행 권한이 같지 않다.
- **개발자/연구 도구:** Python API, 터미널 명령, 데이터 수집·정제·학습·백테스트 스크립트. 일반 GUI에 해당 버튼이 있다는 뜻이 아니다.
- **이번 변경의 범위:** 연구용으로 보존한 MK1.2를 별도 모의 외부 신호로 연결하고 모델별 점수·원매수 출처·매도 기준을 구분한다. 기존 모델 가중치·정제 DB는 바꾸지 않는다. 실제 주문 검증 여부는 개발일지의 검증 결과와 구분한다.

| SIGNAL-15 | 종목별 모델 추정확률 표시 | **관심종목** 표의 MK1·MK1.1·MK1.2 독립 열과 선택 종목 상세에서 매수/대기 판단, 추정 성공확률, 판단에 사용한 현재가·조회 시각을 구분해 보여준다 | 실제 적중률·수익률·주문 허가가 아님. 보유/오류/미조회 또는 현재 시세와 불일치·15초 초과 시 최신 점수로 표시하지 않음. 주문 직전 재추론은 별도 |
| SIGNAL-16 | mark1.2 prototype 모의 연결 | 국내 CNN·미국 LSTM 3-seed 연구 모델을 별도 외부 프로세스에서 조회해 `mark1-2-prototype-demo-trigger` 출처의 매수 후보를 만든다 | 명시적 체크·모의 전용, 추정 성공확률 >50%, 해당 매수분 +1%/−0.9%. `research_qualified=false`, `deployment_allowed=false` 유지; 비용 20bp 가정 과거 손실·장중 체결 미검증. 실전 사용 차단 |

기본 선택된 두 prototype은 **CatBoost 3-seed 앙상블**이다. 선택형 MK1.2는 **국내 CNN·미국 LSTM 3-seed** 신경망이며 원본 연구 모델을 승격한 것이 아니다. 세 모델 모두 연구 기준 미통과이며 실제 장중 성공률·수익성은 검증되지 않았다.

## 10. 모델 학습·추론 계열

학습/연구는 기본 GUI의 자동 기능이 아니다. 다음 모델들은 입력·정답·선택 결과가 서로 다르다.

| 초기 mark1 | 과거 30봉+진입가 → +1%/−0.9% 장벽 사건 | MLP/LSTM/GRU/TCN/Transformer 비교; 저장 선택은 양 시장 `mlp_no_price_aug` | 과거 비교 연구 |
| mark1 Deep | 심층 모델·여러 seed로 같은 목표 비교 | Deep MLP/ResNet18·34/Inception 계열; 저장 선택 국내 Inception·미국 ResNet34 | 연구용, 현재 외부 prototype 아님 |
| mark1 Selective | 30봉에서 만든 184특징·실제 시가 진입 | CatBoost/LightGBM 및 선별 정책 비교 | 두 시장 모두 연구 기준 미통과 |

소스는 [학습 도구 폴더](../examples), [초기 mark1 문서](mark1-strategy.md), [심층 연구](mark1-deep-protocol.md), [선별 연구](mark1-selective-protocol.md), [0.5/0.4 연구](MARK1_0504.md)에 있다. 과거 경로를 사용하는 백테스트/내보내기는 [새 연구 호환 명령](research-tools.md)으로 실행한다. 원래 기록을 다시 쓰지 않으며 전체 연구 수치 재실행 검증과는 구분한다.

## 12. 기능이 있다고 오해하면 안 되는 것

| 항목 | 현재 상태 |
|---|---|
| 앱을 닫아도 클라우드에서 자동으로 계속 거래 | 그런 상시 클라우드 서비스가 아님. 로컬 실행 프로세스/컴퓨터가 동작해야 로컬 감시가 지속됨 |
| GUI에서 자동으로 모든 모델을 재학습·승격 | 없음. 학습/선택/내보내기는 별도 연구 도구이며 승격은 별도 작업 |
| 현재 기본 GUI의 자동 마감 전 전량 청산 | 정책은 기본 선택. 사용자가 감시·자동주문을 켜야 동작하며 실제 체결/전량 소진 보장 아님 |
| 주문 OFF를 누르면 미체결 주문까지 취소 | 아님. 새 전송 차단이며 취소 요청은 별도 |
| 확률 50% 초과 = 실제 장중 매매 성공률 50% 초과 보장 | 아님. 모델 추정값이며 장중 경로·체결·비용 후 수익성 미검증 |
| +1%, +0.5% 도달 시 그 가격에 반드시 체결 | 보장 안 됨. 조회 지연·갭·호가·미체결 영향 |
| 현재 세 prototype의 실전 사용 | 차단된 모의 전용 경로. 일반 브로커 실전 인터페이스와 구분 |
| 모든 주식·상장폐지·기업행사의 완벽한 역사 DB | 보장 안 됨. 수집 가능한 현재 카탈로그/응답과 별도 품질 검사 범위 |
| 유통주식 수 자체를 이용한 저유통주 판별 | 현재 정제는 거래대금/거래량 기반 저유동성 필터가 중심 |
| 증권사 전체 거래내역의 세후 손익·세금 신고 | 제공하지 않음. 앱 장부 기반 확인된 원가의 세전 손익 |
| 모델까지 wheel 하나에 내장 | 아님. 코드/worker는 wheel, 검증된 모델 묶음은 별도 지정. GUI/추론과 연구 의존성도 분리 |

이 문서는 기능의 **존재·사용 위치·제약**을 기록한 현황표이며, 삭제 승인 목록이나 수익성 인증서가 아니다. 실제 개선/삭제 여부는 [적대적 감사의 우선순위와 승인 기준](audits/2026-09-24/README.md)을 따른다.
