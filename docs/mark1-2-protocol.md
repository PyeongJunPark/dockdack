# Mark1.2 prototype — 가격 증강 신경망 비교 계획

2026-09-24 학습 전 고정 계획과 실행 기록. 당시 기존 MK1·MK1.1 prototype과 GUI·자동주문 설정은 변경하지 않았다. 아래 완료 상태는 학습·평가 완료만 뜻하며 수익성 개선이나 주문 승인이 아니다. 2026-09-25 후속 사용자 선택형 모의 연결은 별도 절에서 구분한다.

## 목표와 데이터

- 사용 장치: 로컬 RTX 5080 16GB, PyTorch 2.11.0+cu128. CUDA 또는 해당 GPU가 없으면 중단하며 CPU 학습으로 자동 대체하지 않는다.
- 정제 `clean-20260916-v1` DB와 불변 원시 캐시를 해시 대조해 읽는다. 미국 FCEL·BNED·BBSI·SONY는 사전 선언한 가격 기준 문제로 전체 기간 격리한다. 원본 DB를 고치지 않으며 다른 기업행사·생존편향 위험이 사라지는 것은 아니다.
- 과거 완료 30봉 OHLCV + 후보 진입가, **고가 ≥ 후보가×1.01 및 저가 > 후보가×0.991**를 성공으로 학습한다. 양쪽 장벽 도달은 손절 우선 실패다.
- 일봉은 임의 장중 진입 이후의 고저점 순서를 제공하지 않는다. 가격 질의 기능은 만들지만 그런 첫 도달 확률을 검증했다고 주장하지 않는다.

## 공정한 비교와 가격 증강

MLP 대조군, 단순 RNN, LSTM, GRU, 1D CNN, 1D ResNet-18/34 계열의 **7개 구조**를 비교한다. 모든 구조는 동일한 18개 과거/질의 특징·30봉 역사 인코더와 별도 가격 질의·4개 출력(익절만/손절만/양쪽/미도달)을 사용한다. 184개 통계 특징을 쓰는 기존 CatBoost와는 다른 실험이다.

고정 배율은 실제 시가의 `1.0, 0.99, 0.995, 1.005, 1.01`이다. 기본 사건을 시간 구간에 먼저 배정하고 매 epoch 실제 시가 + 비단위 배율 하나를 균등 추출한다. 증강 정답도 해당 가격으로 다시 계산한다. 모델 초기화/Dropout 난수와 별개인 생성기로 동일 seed·epoch의 기본 사건 순서와 배율 표본을 맞춘다.

손실은 `actual BCE + 0.25 actual 4-class CE + 0.5 augmented BCE + 0.125 augmented 4-class CE`로 고정한다. 실제:가상 손실 가중치는 **2:1**이며 가상 학습이 없는 기존 최종 모델보다 증강을 명시적으로 강화한 새 비교다. 이 비율이 최적이라고 미리 주장하지 않는다. 클래스 가중치나 성공 표본 과다추출은 하지 않는다.

후보가격을 목표일 고저점에 맞춰 고르거나 유리한 가상가격만 남기지 않는다. 과거 봉 자체를 조작하지 않는다. 하루 가격 변형은 독립된 실제 거래가 아니며 기본 사건 수·epoch별 제시 수·파라미터 수를 따로 기록한다.

## 학습·검증 순서

| 단계 | 조건 |
|---|---|
| GPU 스모크 | 7구조 forward/backward·저장/복원·정상 프로세스 종료, 단위 회귀 |
| 예비 실행 | 시장별 2만 기본 사건, 2 epoch, 최신 fold; 속도·메모리·재개 확인용, 모델 선정에 사용 안 함 |
| 공통 본 비교 | 최대 150만 학습/15만 종료검증 표본, 7구조×2시장×2시간구간×seed42 = 28회 |
| 재현성 확인 | 시장별 선정 구조의 seed43·44를 두 구간 모두 추가: 8회, 총 36회 |
| 최종 산출 | 3-seed raw log-odds 평균→별도 Platt 보정, 가격배율별 민감도·역사 포트폴리오 평가 후 별도 prototype 보존 |

`walk_2022`: 2012~2019 학습 → 2020 조기 종료 검증 → 2021 확률 보정 → 2022 모델 비교. `walk_2024`: 2014~2021 학습 → 2022 조기 종료 검증 → 2023 확률 보정 → 2024 모델 비교. 후속 연도 경계에서 과거 30거래일 입력 중복을 제거하고 학습 구간 종목군만 허용한다. train/tune은 정답과 무관한 고정 표본, 보정/비교는 적격 전체 표본이다.

공통 width48, dropout0.2, batch1024(실제+가상 총2048), AdamW lr0.0003/weight decay0.001, gradient clip1, 3epoch warmup/cosine decay. 최대60epoch, 최소12epoch, 개선 없는12epoch 후 종료한다. 오래 학습할 수 있지만 과적합을 막기 위한 종료 검증은 유지한다. GPU 메모리 사용 상한은 전체의65%다.

CNN/ResNet은 BF16 혼합정밀도 학습, RNN 계열 내부는 FP32이며 Windows CUDA cuDNN recurrent 호출만 비활성화한다. epoch 선택은 실제 시가의 CUDA FP32 BCE, 보정과 구조 비교는 실제 시가의 **CPU FP32** 추론으로 실시한다. 가상가격까지 똑같이 보정됐다고 간주하지 않는다.

## 선택·합격·평가를 구분

양쪽 개발 구간에서 연구 기준을 모두 통과한 후보를 최우선으로 한다. 다음은 양쪽에서 신호 증거가 충분한 후보이며, 같은 등급 안에서는 가장 낮은 성공률 신뢰구간 하한 → 평균 비용 후 수익 하한 → 평균 Brier skill로 비교한다. 증거가 충분한 후보도 없으면 Brier skill 기반 **진단용** 후보를 남기며 합격으로 표시하지 않는다. 시장별 구조를 잠근 후 추가 시드를 학습한다.

현재 `p>0.5`를 고정해 비교하며 정확히50%는 대기다. 연구 합격은 최소50신호·20신호일·10종목, 관측 성공률65% 이상, 10일 블록×2,000회 재표집의95% 성공률 하한57.9% 초과, 왕복20bp 후 수익 하한 양수를 요구한다. 반복 모델 탐색의 불확실성까지 완전히 보정하는 통계 보장은 아니다.

2025년 이후는 이미 연구에서 본 **재사용 역사 평가**로만 사용하며 가중치/구조 선택에 쓰지 않는다. 이후 실제 시가 진입·정수주·자금 한도·보유형/종가 청산·0/10/20/40bp 비용을 나눠 평가한다. 가격 증강 사례를 추가 실제 체결 수로 세지 않는다. 기존 모델과 비교해 손실이어도 수치를 숨기거나 실전 승인으로 표시하지 않는다.

## 보존·재개

코드·데이터·설정 해시 계약과 optimizer/RNG를 포함한 2세대 중간 저장으로 재개한다. 새 세대와 해시를 저장한 뒤 포인터를 바꾸므로 중간 종료 시 직전 검증 세대를 유지한다. 같은 출력 폴더 동시 실행은 OS 잠금으로 차단한다. 계약 또는 체크포인트 해시가 다르면 중단하고 기존 산출물을 보존한다. 파일이 있다는 이유만으로 완료로 인정하지 않는다. 새 결과는 `outputs/mark1/`의 전용 새 실행 폴더에 두며 기존 MK1/MK1.1 모델·원장·자동매매 프로세스는 건드리지 않는다.

## 후속 선택형 모의 연결 · 2026-09-25

사용자 요청으로 기존 `mark1 prototype`·`mark1.1 prototype`의 기본 선택은 그대로 두고, `mark1.2 prototype`을 **기본 해제된 세 번째 외부 AI 신호기**로 추가했다. 사용자가 **신호 연결 → 모델·연결 설정**의 Mark1.2 체크를 명시적으로 켜야 별도 프로세스가 생성된다. 모델 ID `mark1-2-prototype`, 소스 ID `mark1-2-prototype-demo-trigger`와 별도 JSON/판단 상태를 사용한다. 앱 실행·모델 선택만으로 감시 또는 자동주문을 켜지 않으며 실전 환경 연결·신호·주문은 차단한다.

별도 어댑터는 봉인된 모델의 완료 30봉 + 현재가에 대한 추정 성공확률을 사용한다. `p>0.5`면 모의 매수 후보이며 정확히 0.5는 대기다. 확인된 원매수 체결은 다른 모델과 lot/출처를 분리하고 해당 체결분에 +1% 익절·−0.9% 손절 기준을 적용한다. 종목별 모델 추정확률은 별도 GUI 열로 표시하며 실제 적중률, 체결 보장, 비용 후 수익률 또는 주문 허가를 뜻하지 않는다. 모델 파일·가중치·보정·이 학습 계획의 임계값은 바꾸지 않았고, [실패한 후속 MLP 필터](../reports/mark1-2-20260925-review/REPORT.md)는 연결하지 않았다.

이 경로는 사용자가 요청한 **모의투자 실험**이지 연구 합격이나 실전 배포가 아니다. 2025+ 재사용 역사 평가에서 왕복 20bp 비용 후 보유형 국내 −5.8640%, 미국 −6.9049%였고 장중 실제 체결·진입 후 고저점 순서는 미검증이다. 실사용 전 사용자가 모델별 위험 문구·주문 상한·자동주문 ON 절차를 별도 확인해야 한다.
