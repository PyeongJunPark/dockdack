# mark_1: 드문 신호의 정밀도를 높이기 위한 후속 문헌 검토

조사일: 2026-09-16. 사용자의 새 우선순위는 **신호 빈도를 줄여도 실제 매수 신호의 성공 비율을 높이는 것**이다. 아래는 1차 문헌을 확인한 연구 설계 제안이며, 성과 확인이나 수익 보장이 아니다. 실제 실행한 범위·분할·선택 규칙은 새 실험의 고정 manifest가 기준이다. 기존 심층 모델의 결과를 바꾸거나 숨기지 않는다.

## 먼저 바꿔야 할 평가 목표

전체 표본의 accuracy와 BUY precision은 다르다. 실패 정답이 많은 데이터에서 모두 대기/실패로 예측하면 accuracy가 높아도 쓸 수 있는 매수 신호는 없다. 이번의 주 지표는 `성공 BUY 수 / 전체 BUY 수`, 함께 볼 지표는 신호 수·신호 발생 날짜 수·종목 수·비용 후 기대수익·구간별 안정성이다. BUY가 0건이면 정밀도는 100%가 아니라 **정의되지 않음/증거 부족**이다.

입력은 완료된 과거 30개 일봉과 현재 후보 매수가로 유지한다. 성공 정답은 `high >= entry * 1.01 AND low > entry * 0.991`, 양쪽 장벽을 모두 찍으면 실패다. +1% 익절/−0.9% 손절을 바꾸지 않는다. 다만 `p > 0.5`는 최소 조건으로 유지하면서, 검증으로 정한 더 엄격한 보류 조건을 추가하는 방향을 검토한다. 이는 모든 `p > 0.5`를 매수했던 기존 정책과 다른 **선별 정책**이다. 점수를 성공확률인 것처럼 표시해서는 안 된다.

## 구현 가능한 후보 5개와 우선순위

### 1. 별도 검증 구간에서 정한 보류 임계값 — 가장 먼저

기존 및 새 모델의 보정된 성공확률로 작은 **사전 고정** threshold 후보 집합을 평가한다. 신호가 드물어져도 충분한 날짜에 반복되는지 확인한다. 임계값마다 정밀도, 신호 수, 신호 날짜 수, 비용 후 수익의 곡선을 저장한다. 전체 Brier가 가장 낮다는 이유만으로 최종 모델을 고르지 않는다.

확률 보정, threshold 선택, 선택 후 평가를 같은 자료에서 동시에 끝내면 낙관 편향이 생긴다. 최소한 선택에 사용하지 않는 뒤쪽 확인 구간을 둔다. calibration에서 잘 나오는 threshold가 없으면 **신호를 내지 않는 실패/보류 결과**가 정상적인 결론이다. 일일 top-k 강제 매수는 이 요구와 맞지 않는다.

### 2. 앙상블 불일치 보류 — 비교적 작은 추가 비용

여러 seed와 서로 다른 모델 계열의 실제 시가 예측을 같은 표본에서 모은다. 후보 점수는 평균 확률, 구성 모델 최솟값, `평균 확률 − k × 구성 모델 표준편차`처럼 단순하게 제한한다. `k`와 조합 수는 사전 고정한다. 낮은 불일치나 높은 최솟값에서만 채택하는 정책을 대조군과 비교한다.

이 값은 **보수적 순위 점수**일 뿐 통계적 하한이나 새 성공확률이 아니다. 구성 모델을 성과가 좋은 seed만 골라 만들지 않는다. 예를 들어 세 개 seed가 전부 같은 누락 특징을 가진다면 모두 확신하며 틀릴 수 있다. GPU를 오래 쓰는 것은 가능하지만 seed 수만 늘린다고 새로운 정보가 생기지는 않는다.

### 3. BUY 전용 선택 head와 안전 사건 학습 — 목적함수 변경 후보

일반적인 SelectiveNet을 그대로 쓰면 모델이 쉬운 **실패/비매수** 표본만 받아들여 높은 accepted accuracy를 얻을 수 있다. BUY 정밀도가 목적이라면 선택 head를 `이 표본에서 BUY를 제안할 가치`로 정의하고, 채택한 BUY의 오류를 직접 측정해야 한다. 모든 표본에 대한 보조 BCE/4-class loss는 남겨 쉬운 소수 표본만 암기하는 것을 줄인다. 최종 gate는 별도 날짜에서 검증한다.

현재 4개 사건 `take_only / stop_only / both / neither`는 성공과 위험을 분리하는 데 쓸 수 있다. `p_success = p(take_only)`, `p_stop = p(stop_only) + p(both)`로 해석하며 낮은 stop 위험을 추가 조건으로 비교할 수 있다. **서로 종속인** `P(take)`와 `P(no stop)`를 독립이라고 가정해 곱하면 안 된다. 조건부 head를 쓰려면 `P(no stop) × P(take | no stop)`처럼 일관된 분해가 필요하다.

false-positive 가중치를 높이는 loss/oversampling은 점수의 사전확률 해석을 바꾼다. 이를 시도할 때는 별도 변형으로 기록하고 독립 calibration을 한다. 단순히 출력값만 크게 만드는 것은 정확도 개선이 아니다.

### 4. 시간 순서 밖 예측으로 학습한 메타필터 — 재학습 후보

기본 모델이 과거에서 학습하고 **그 이후에 예측한** 신호와 그 결과를 모아 2차 모델을 학습한다. 입력은 기본 모델의 점수·앙상블 불일치·과거 변동성/유동성·시가 갭 등, 그때 이미 알 수 있었던 정보로 제한한다. 얕은 로지스틱/작은 MLP와 비선형 모델을 비교할 수 있다.

기본 모델이 학습에 사용한 행에 다시 예측한 in-sample 점수로 메타모델을 학습하면 실전보다 쉬운 문제를 만들어 누수/낙관 편향이 생긴다. 날짜 단위 out-of-time 예측을 먼저 만들고, 그 예측의 생성 모델·학습 종료일을 함께 저장해야 한다. 메타필터는 원래 없는 정보 우위를 자동으로 만들어내는 방법이 아니다.

### 5. 국면별 전문 모델 — 첫 선별 결과를 본 뒤 별도 실험으로

과거 30봉만으로 계산한 변동성·추세·과거 거래량 등으로 사전 정의한 국면을 나누거나 작은 router를 학습한다. 각 전문 모델의 신호가 특정 한 해/한 종목에만 몰리는지 검사한다. TRA는 이 동기의 1차 퀀트 문헌이지만, 현재 입력에 맞춘 단순 국면 분할은 TRA의 optimal-transport 학습을 재현한 것이 아니다.

국면 정의에 당일 최종 고저가·거래량을 쓰지 않는다. router가 과거 예측 오차를 이용한다면 정답이 공개된 시점 이후의 과거 오차만 허용한다. 구간을 많이 나눌수록 표본이 적어지므로 희귀 신호의 우연한 고정밀도를 더 경계해야 한다.

## 사전 고정 프로토콜 제안

아래는 연구 권고이며 실행 설정을 대신하지 않는다. 실행 전에 시장별 날짜·후보 수·threshold 집합·seed·최소 증거량·epoch 상한·early stopping 기준을 manifest에 저장하고 hash로 잠근다.

1. **정답/비용 고정:** +1%/−0.9%, 양쪽 터치 실패, 실제 시가 진입을 기본 평가로 유지한다. 가상 가격 증강은 독립 관측이 아니며, 하루 저가보다 낮아 거래되지 않은 가상 가격이 쉬운 성공 정답을 만드는 문제를 기록한다. precision 실험에는 실제 시가 표본을 우선한다.
2. **시간 분리:** 학습 → tune → calibration/선별 선택 → 다음 연도 확인. 여러 종목의 같은 날짜를 같은 구간에 둔다. 기존 30거래일 purge 및 train-only universe/스케일러 규칙을 유지한다.
3. **첫 선별 기준 예:** 별도 선택 구간에서 최소 100개 신호·30개 신호 날짜, 관측 precision 60% 이상을 연구 후보로 삼고, 뒤쪽 확인 구간에서도 충분한 표본/날짜와 같은 방향의 개선을 요구한다. 이 숫자는 수익/정확도 보장이 아니라 **실행 전에 정할 운영적 증거 기준**이다. 결과가 마음에 들지 않는다고 최소 건수를 낮추지 않는다.
4. **확률과 점수 구분:** 보정 p, ensemble spread, 선별 score, 실제 gate threshold를 각각 저장한다. 보류 이유를 반환하고 기존 GUI/자동주문 모델은 검증 없이 교체하지 않는다.
5. **불확실성:** 날짜 cluster와 연속 10거래일 moving-block bootstrap을 진단으로 사용한다. 관측 precision의 하한·거래 기대값의 하한을 함께 보고한다. 이 bootstrap은 금융 의존성·국면 변화를 완전히 해결하는 엄밀한 conformal 보장이 아니다.
6. **기간별 안정성:** 전체 수치 외에 분기/연도, 국내/미국, 종목 집중도, 평균 시가 갭, 보유/당일 청산, 비용 0/10/20/40bps를 동일하게 보고한다. 총수익이 좋아도 실제 BUY precision이 나빠지면 목표 달성으로 보고하지 않는다.
7. **연구 이력 보존:** 이미 반복 확인한 2025년 이후 구간은 `재사용 과거 평가`로 적는다. 모델 선택이나 threshold 결정에 참조한 구간을 새 이름으로 바꿔 미사용 최종 시험이라고 하지 않는다. 새 데이터/미래 고정 예측 평가가 없으면 전향적 일반화를 입증했다고 할 수 없다.
8. **실패 정책:** 통과 후보가 없으면 임의로 가장 덜 나쁜 후보를 배포하지 않는다. 0건 정책은 자본 노출을 없애는 대기 상태이지 AI 정확도 성공이 아니다. 실패/보류도 전체 후보 표와 함께 남긴다.

## 보장으로 오해하면 안 되는 사항

- 신호를 줄이는 것만으로 precision이 반드시 좋아지지는 않는다. 고확률 꼬리에서 오히려 과신한 모델도 있기 때문에 실제 빈도를 확인해야 한다.
- Learn then Test에서 서로 다른 threshold의 p-value 간 의존을 허용하는 것과, p-value를 계산하는 기초 관측의 IID 가정을 없애는 것은 다르다. 다중검정 보정만 적용하고 종목×날짜의 독립성을 가정하면 금융 의존성은 남는다.
- 보정된 60% 예측은 그 종목 한 번의 결과를 보장하는 수치가 아니며, 시장 국면이 바뀌면 calibration도 변할 수 있다.
- 비용을 무시한 성공률과 돈을 버는 전략은 다르다. 정확히 +1%/−0.9% 두 결과만 있다고 가정해도 왕복 0.2% 비용이면 단순 손익분기 성공률은 약 57.9%다. 갭·미도달·체결 오차를 반영하면 이 식은 불충분하다.
- 일봉 전체의 고가·저가는 임의 장중 매수가 **이후**의 순서를 알려주지 않는다. 이번 과제로 개선할 수 있는 것은 명시한 일봉 사건의 예측/선별이며, 실제 장중 트리거의 정확한 경로 검증에는 분봉 등 추가 관측이 필요하다.

## 이번 권고의 결론

우선순위는 **평균 확률 중심의 모델 순위를 BUY 정밀도 중심의 선별 검증으로 바꾸는 것**, 다음은 **앙상블 불일치/손절 위험을 이용한 보류**, 그다음은 **과거 밖 예측으로 만든 메타필터 또는 BUY 전용 선택 학습**이다. 층을 더 쌓는 일이나 학습 시간을 늘리는 일은 이 검증 구조 안의 후보 수단이다. 어떤 문헌도 현재의 정제 일봉 자료에서 목표 성공률이나 수익을 반드시 얻을 수 있다고 증명하지 않는다.
