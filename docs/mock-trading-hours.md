# 모의투자 거래시간 확인

확인일: 2026-09-15. 실전계좌가 아닌 키움 REST **모의계좌** 기준이다.
시세 조회 성공, 주문 접수 성공, 체결 확인은 서로 다른 상태다.

## 현재 자동주문 적용 범위

| 구분 | 한국시간의 평시 범위 | 처리 |
| --- | --- | --- |
| 국내 장전 접수 | 08:30~09:00 | 사용자 요청으로 자동주문 제외 |
| 국내 장중 | 09:00~15:20 | 기존 신호·잔고·주문 상한 검증 후 모의주문 |
| 국내 종가 동시호가 | 15:20~15:30 | 기존 정규장 정책 유지. 접수 후 종가 결정까지 기다릴 수 있음 |
| 국내 시간외·NXT | 정규장 이후 등 | 별도 시간외 주문은 활성화하지 않음. 모의 NXT 거래는 미지원 |
| 미국 정규장 | 서머타임 22:30~다음날 05:00 / 표준시 23:30~다음날 06:00 | 현재가 지정가 모의주문 |
| 미국 프리·애프터·주간거래 | 정규장 외 | 아래 9/15 프리마켓 시험은 장시작전 거절. 다른 장외 구간은 미확인으로 임의 활성화하지 않음 |

휴장·조기폐장·특별 개장은 거래일 캘린더를 따른다. 위 시각을 매일 고정 적용하지 않는다.
미국 장외 전체가 미지원이라고 단정하지 않는다. 아래 **실제 시험 시점의 프리마켓 거절**과 다른 시간대의 미확인을 구분한다.
국내 장전 접수 제외 선택을 종가 동시호가의 기존 정책 변경으로 확대 해석하지 않았다.
지정가·시장가 모두 주문 접수가 곧 즉시 체결을 보장하지 않는다.

## 확인 근거와 한계

### 사용자 승인 1주 모의 시험 (2026-09-15)

- 17:58:03 KST / 04:58:03 EDT: NASDAQ AAPL 1주 매수, 조회가 $330.8003을 지정가로 전송.
  `return_code=2`, `1517` 가격 소수점 형식 오류로 거절. 주문번호가 없고 접수되지 않았다.
  이 결과는 거래시간 지원 여부의 증거가 아니다.
- 가격 단위 처리를 고친 후 사용자가 **별도로 재승인**한 1회 시험:
  18:03:33 KST / 05:03:33 EDT, 새 조회가 $330.7700 → 지정가 $330.77, 수량 1주.
  모의 `ust20000` 응답은 `return_code=20`, `[2000](RC4057:모의투자 장시작전)`.
  이 시점의 현재가 지정가 매수는 모의 서버가 차단했다. 접수 번호가 없으므로 취소할 주문도 없다.
- 두 번 모두 `https://mockapi.kiwoom.com`만 사용했다. 각 시도는 전송 전 저널을 기록하고 자동 재전송하지 않았다.
  첫 시도와 재승인 시도를 별도 식별자로 보존했다. 실전 주문은 하지 않았다.
- 18:04:57 KST 후속 조회에서 AAPL 보유 0주, 미체결 잔량 0주, 당일 체결 0주(조회 행 0개)를 확인했다.
- 따라서 자동매매는 기존 정규장 범위를 유지한다. 이번 결과를 애프터마켓·모든 프리마켓 구간의 지원 여부나
  실전계좌 가능 시간에 일반화하지 않는다. 추가 장외 시험은 별도 사용자 승인 또는 공식 근거가 필요하다.

### 공식 자료

- [키움 REST 모의투자 안내](https://openapi.kiwoom.com/intro/mockInvestInfo?dummyVal=0): 국내 KRX 전용,
  모의 NXT 거래 미지원, 미국 NYSE·NASDAQ·AMEX 지원. 세부 규정은 각 모의투자 운영규정으로 안내한다.
- [상시 모의투자 운영규정](https://einfomax.kiwoom.com/kw/vts/#/vts/operating/1)과
  해당 페이지가 제공하는 [공식 공개 화면 코드](https://einfomax.kiwoom.com/kw/js/app_kw_vts_bundle.js):
  국내 장전 접수·장중·종가 결정 구간, 지정가·시장가 주문을 구분한다.
  예약주문 설명을 현재 REST API의 장외 즉시 체결 지원으로 해석하지 않는다.
- [국내 매수](https://openapi.kiwoom.com/guide/apiGuideContents/13/kt10000) /
  [국내 매도](https://openapi.kiwoom.com/guide/apiGuideContents/13/kt10001): 모의 KRX 경로와
  지정가 `0`, 시장가 `3` 코드. 공통 명세에 나오는 모든 주문 코드가 모의 환경에서 허용된다는 뜻은 아니다.
- [미국 일반 모의투자 안내](https://www.kiwoom.com/h/mock/ordinary/VMockFostockInfoView)는
  비로그인 상태에서 세부 내용을 읽을 수 없었다. 대학생 모의투자대회의 미국 시간표를 일반 모의투자 규정으로 대신 사용하지 않는다.
- [키움 공식 REST 명세](https://raw.githubusercontent.com/Kiwoom-Securities/Kiwoom-REST-API/main/kiwoom/_data/kiwoom_api_spec.json)는
  미국 주문 `ust20000`·`ust20001` 및 `/api/us/ordr`를 제공하지만, 일반 모의투자의 장외 지원시간을 확정하지 않는다.
- [NYSE 공식 운영시간·휴장일](https://www.nyse.com/trade/hours-calendars)은 정규장과 거래일 근거이며,
  키움 모의투자의 장외 지원 근거와는 구분한다.

## 계속 켜 둔 앱의 동작

- 감시와 자동주문이 ON이면 장외에도 조회·신호 파일 처리를 계속한다. 정상적인 장 마감만으로 OFF로 바꾸지 않는다.
- 거래시간에 들어오면 다음 종목 조회·신호 판단에서 자동주문을 재개한다. 켜기 버튼을 다시 누르지 않는다.
  API 호출 간격과 순회 때문에 개장 정각에 모든 종목을 동시에 주문하지는 않는다.
- 미체결 주문이나 미확정 접수, 잔고 부족, 신호 만료, 보통주 분류 실패 등은 거래시간이어도 주문을 막는다.
- OFF·중지 또는 안전 오류로 자동주문이 꺼진 경우 개장만으로 다시 켜지 않는다.
- 주문 전과 HTTP 속도 조절 대기가 끝난 직전에 시간을 다시 확인한다. 폐장 후 전송 및 자동 재전송을 허용하지 않는다.
- 장외 조회에는 직전 체결가가 반환될 수 있다. 조회 시각이 새롭다는 것만으로 해당 시간대의 실제 체결 시세로 간주하지 않는다.

`tests/test_session_resumption.py`는 가짜 브로커와 임시 DB로 한국·미국 개장 자동 재개,
익절·손절, 장전 제외, 폐장 경계, OFF·중지·안전 오류를 검증한다. 이 테스트 통과는 실제 서버 체결 증거가 아니다.
