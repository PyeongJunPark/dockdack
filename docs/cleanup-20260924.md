## 단일 작업 폴더로 옮긴 뒤의 경로

통합 위치는 `C:/Users/user/Desktop/dockdack`이며 정제 DB는 그 안의 `data/kiwoom_daily/clean-20260916-v1/`에 둔다. 일반 GUI·모델·선택 패키지·설정/장부 실행기는 현재 저장소 안의 경로를 먼저 사용한다. 세 가지 mark1 미리보기와 미국 데이터 점검 실행기도 현재 저장소의 정제 DB를 우선하며, 없을 때만 예전 형제 폴더를 호환 경로로 확인한다. 명시한 `--database-dir` 또는 `--clean` 인수는 자동 선택보다 우선한다.

고정 학습 코드·모델 번들·연구 결과 JSON에 기록된 과거 절대경로와 해시는 변경하지 않는다. 새 mark1/deep/selective 학습은 `--db-dir data/kiwoom_daily/clean-20260916-v1`과 새로운 출력 폴더를 명시할 수 있다. 이미 끝난 연구의 백테스트/재내보내기는 학습 기록의 `database_path`를 다시 읽으며 별도 DB 경로 재지정 인수가 없다. 따라서 예전 폴더를 제거한 뒤 해당 과거 실행을 그대로 재개하는 것은 지원되지 않는다. 현재 저장된 추론 번들과 GUI 사용에는 이 과거 DB 경로가 필요하지 않다. 과거 실행을 재현할 때는 원본 기록을 보존한 채 경로 이전을 명시적으로 지원하는 별도 재현 절차가 필요하며, 이번 정리는 해시 검사를 우회하거나 연구 기록을 덮어쓰지 않는다.
