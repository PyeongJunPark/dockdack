- 특히 `outputs/mark1/selective-deps`와 `prototype-gui-deps`는 로컬 실행기에 필요한 패키지이므로 삭제하지 않는다. 다른 컴퓨터는 `uv sync --extra gui --extra prototype`으로 설치한다.
