# Mark1.5 이후 일봉 딥러닝 연구 로드맵

작성: 2026-09-27. 아래 **방법별 후보**는 당시 논문에서 아이디어를 빌려 적은 최초 실험 설계이며 논문 재현이나 현재 모델 목록 자체가 아니다. 이후 사용자의 요청으로 Mark1.5–1.12 일부 방법이 실제 CUDA 학습/동결 번들과 모의 신호로 구현됐다. 초기 구상의 `Mark1.9 강화학습`, `Mark2.0 앙상블` 번호는 **현재 저장 모델 번호가 아니다**. 실제 Mark1.9는 E2 평균−불확실성망, Mark1.10은 E3 유전탐색이며 강화학습/앙상블은 아직 별도 버전·가중치·주문 연결이 없다. 모의 실험 선택은 연구 수익성 검증이나 실전 배포 승인이 아니다.

## 비교 가능한 공통 문제

- 의사결정 시점은 거래일 `t`의 일봉이 **완전히 확정된 뒤**, 다음 거래일 `t+1` 개장 전이다. 입력은 우선 종목별 최근 **완성된 30개 OHLCV**로 고정한다. 개장 10분 전 판단을 요구하는 실행 계약에 맞춰, 그 이후 생기는 `t+1` 가격·거래량은 특징에 넣지 않는다.
- 공통 연구 목표는 `t+1` **시가 매수·같은 날 종가 매도**의 비용 차감 수익이다. 같은 거래일 고가·저가만으로 0.5% 익절과 0.4% 손절의 선후를 알 수 없고, 일봉 백테스트의 시가·종가 체결도 실제 주문 체결 보장이 아니다. 장중 손절/익절 연구는 분봉·체결 자료와 별도 실행 계약이 필요하다.
- 시장별 종목 집합과 거래량 상위 100종목은 그 날짜의 판단 시점까지 알려진 정보로 재구성한다. 현재 카탈로그에서 살아남은 종목만 고정 선택하면 상장폐지·생존편향이 남는다. 순위 모델에는 같은 날짜의 *전체 후보 집합*이 필요하다.
- 종목당 시작 자산 최대 10%, 동시 보유 최대 10종목, 정수주·현금·레버리지 없음, 왕복 비용 기본 20bp를 공통 비교 회계로 둔다. 이는 연구 가정이며 실제 수수료·세금·호가충격의 확인을 대신하지 않는다.

## 방법별 후보

| 버전 | 참고 방법과 모델 출력 | 현재 일봉으로 가능한 것 / 추가로 필요한 것 |
|---|---|---|
| **Mark1.5 — 순환계열** | 30일 OHLCV의 LSTM·GRU·가벼운 TCN을 비교해 **다음 날 순수익 기대값**과 비용 후 양수 **확률**을 따로 출력한다. 종목 선정은 보정된 기대값/확률과 상위 순위로 평가한다. [Fischer·Krauss의 LSTM 원문](https://www.iwf.rw.fau.de/files/2015/12/11-2017.pdf)은 240일 수익률 시퀀스와 1일 롱숏을 사용했으므로 30일·롱온리 모델은 적용 실험이지 논문 재현이 아니다. | 30일 일봉으로 즉시 설계 가능. 확률은 별도 보정 전에는 신뢰도 숫자로 표시하지 않는다. |
| **Mark1.6 — 이미지 CNN** | 30일 OHLCV 차트를 결정적 규칙으로 이미지화한 CNN과 기술지표-시간 격자 CNN을 비교한다. 출력은 동일한 다음 날 **순수익 기대값/매수·관망 확률**이며, 임의의 그림 모양 점수를 수익 확률로 오인하지 않는다. [Jiang·Kelly·Xiu 원문](https://economics.yale.edu/sites/default/files/2023-11/The%20Journal%20of%20Finance%20-%202023%20-%20JIANG%20-%20Re%25E2%2580%2590%20Imag%20in%20ing%20Price%20Trends_0.pdf)은 OHLCV 이미지로 미래 **5·20·60일** 상승을 예측한다. [Sezer·Ozbayoglu 출판사 초록](https://www.sciencedirect.com/science/article/pii/S1568494618302151)은 15×15 지표 이미지의 Buy/Sell/Hold 분류다. | OHLCV 차트는 가능. 긴 기술지표를 계산하려면 30일 이전 기록이 필요하며, 입력 길이가 달라지면 별도 비교군을 둔다. Sezer 본문은 접속 제한으로 확인하지 못했으므로 초록에 명시된 범위만 차용한다. |
| **Mark1.7 — 다종목 관계·순위** | 날짜별 후보 전체를 동시에 넣어 pairwise/listwise 순위 손실과 시장 상황별 attention을 비교한다. 출력은 **상대 순위 점수**, 진입 후보 순서이며 확률이 아니다. [Feng 외의 관계 순위 모델](https://arxiv.org/abs/1809.09441)과 [MASTER 논문](https://ojs.aaai.org/index.php/AAAI/article/view/27767)을 참고한다. | OHLCV에서만 계산한 공통 시장 요약·과거 상관관계는 가능하다. 업종·공급망 관계, 원 논문의 별도 지수·거래대금 특징은 현재 데이터에 있다고 가정하지 않는다. 빠져 있으면 `MASTER-lite`/가격관계 적응형으로 명명한다. [MASTER 공식 코드](https://github.com/SJTU-DMTai/MASTER)가 공개 검증 데이터·전처리 불일치를 밝힌 만큼 검증 마스크와 전처리를 독립 구현·검사한다. |
| **Mark1.8 — 수익·비중 직접 최적화** | 순환망/attention이 **현금 대기·종목별 목표 비중(0~10%)**을 출력한다. 날짜별 비용 후 포트폴리오 수익과 회전율·낙폭 제한을 함께 최적화하며 비중은 매수 확률이 아니다. [Deep Momentum Networks](https://arxiv.org/abs/1904.04912)와 [Momentum Transformer](https://arxiv.org/abs/2112.08534)의 방향·포지션 크기 동시 학습에서 착안한다. | 일별 가상 회계에서 연구 가능. 원문은 선물/롱숏 중심이라 주식 롱온리·시가→종가·현금 제약으로 바꿔야 한다. |
| **번호 미정 — 강화학습 포트폴리오** | 현금·보유·과거 30일을 상태로 하고 **매수·매도·대기와 목표 비중**을 행동으로 학습한다. [Zhang·Zohren·Roberts](https://arxiv.org/abs/1911.10107)와 [DeepTrader](https://ojs.aaai.org/index.php/AAAI/article/view/16144)를 참고한다. | 일봉 기반 오프라인 시뮬레이터 연구는 가능하지만 **주문 시점, 다음 시가 체결, 정수주, 비용, 현금 부족, 미체결, 종목 변동**을 먼저 검증해야 한다. 일봉만으로 장중 손절·호가 체결을 재현할 수 없다. 현재 학습/연결하지 않았다. |
| **번호 미정 — 검증구간 앙상블** | 앞 버전의 동결된 후보 또는 PPO·A2C·DDPG 중 **과거 검증구간**에서 선정한 하나/가중 조합을 *다음* 구간에 적용한다. 출력은 선택된 모델의 신호·비중과 선정 근거다. [Yang 외의 앙상블 논문](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3690996)을 참고한다. | 선행 모델·시뮬레이터가 준비된 다음 진행한다. 평가 대상 기간의 성과로 그 기간에 사용할 모델을 고르면 누출이다. 현재 학습/연결하지 않았다. |

## 자동 실험은 자동 승격이 아님

1. 버전마다 입력 시점·라벨·출력 단위·종목 집합·비용·청산 시점을 담은 설정을 고정한다. 정규화 통계와 가격 증강은 **학습 구간에서만** 만들고, 같은 종목·같은 날짜에서 증강한 표본은 한 분할에만 둔다.
2. 시간순 학습 → 내부 보정 → 다음 구간 평가를 반복한다. 입력창/라벨이 경계를 넘는 표본은 제외하고, 후보 구조·하이퍼파라미터·시드·진입 기준을 평가 전에 동결한다. 기존 Mark1 연구에서 여러 번 본 2022~2024 성적은 새로운 미사용 최종 시험으로 부르지 않는다.
3. 모든 버전을 같은 가상 체결·0/20/40bp 비용·투자 한도로 다시 평가한다. 시장·연도별 총수익, 최대낙폭, 거래 수, 무매매 일수, 신호 빈도, TOP-k 성적, 종목 집중도, 여러 시드의 분산을 남긴다. 확률 출력은 보정도 함께 검증하고, **순위 점수·기대 수익·비중은 퍼센트 확률로 표시하지 않는다**.
4. 다중 모델 탐색의 승자는 사전 규칙으로만 선택한다. 국내·미국 중 한쪽만 수익이거나 거래가 너무 적거나 순수익이 비용/슬리피지 민감도에 무너지면 **선정 없음**을 허용한다. GPU 실행 시간이나 모델 깊이는 수익의 증거가 아니다.
5. 자동 생성기는 재현 가능한 설정·코드/데이터 지문·시드·체크포인트·실패 이유·결과 표를 남긴다. 후속 버전 일부는 사용자의 별도 요청으로 GUI의 모의 신호로 연결됐지만, 모델 선택/학습만으로 감시·자동주문 또는 실전 주문을 켜지 않는다.

## 주문 연결 전 별도 문턱

실전 승격이나 수익성 인정 전에는 모델별 새로운 기간의 paper-trading, 시점별 상장/상폐 포함 종목 목록, 기업행사 가격 조정, 실제 시가/종가 주문 가능성·비용, 계좌 한도·중복 주문·실패 시 관망 처리를 확인해야 한다. 현재 후속 모의 연결은 사용자가 요청한 별도 실험이며, 원 백테스트의 다음 날 시가 진입과 실제 장중 지정가 주문은 다르다. **이 로드맵은 주문 실행 허가나 수익 보장이 아니다.**
