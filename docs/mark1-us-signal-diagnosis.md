# 미국 무신호 진단 — 데이터 문제와 예측력 문제의 구분

진단일: 2026-09-16. `mark_1`의 기존 원본/정제 DB, 학습 캐시, 모델, 확률 보정, 매수 기준을 바꾸지 않고 조사했다. 새 학습·자동주문·추가 데이터 수집·커밋은 하지 않았다.

## 결론

1. **정제 데이터에도 주식분할/병합 전후 가격 기준이 일치하지 않는 구간이 남아 있다.** 해당 구간이 끊기지 않고 30봉 학습 창에 들어간다. 따라서 모든 입력이 충분히 정제됐다고 볼 수 없으며, 재학습 전에 보완해야 한다.
2. **미국의 실제 성공 사례가 없는 것은 아니다.** 2024년 개발 감사 표본 588,175개 중 166,693개가 현재 성공 조건을 충족한다.
3. **선택 모델은 추가 필터 이전부터 성공확률을 50% 이상으로 예측하지 못했다.** 클래스 순서·확률 변환·보정 때문에 신호가 사라진 증거는 없다. 상위 0.1%를 골라도 실제 성공률은 44.14%여서 단순한 확률 과소평가만으로 설명되지 않는다.
4. **모델 선정에 실용적 목표와의 불일치가 있다.** 합격 후보가 없어 전체 확률 오차(Brier)가 가장 낮은 모델을 진단용으로 남겼다. 이는 매수에 쓸 수 있는 모델을 얻었다는 뜻이 아니다.

데이터 이상을 고치면 얼마나 개선되는지는 아직 측정하지 않았다. 일부 불연속이 미국 전체 무신호를 초래했다고 단정하거나, 수정만 하면 수익이 난다고 보장하지 않는다.

## 신호가 사라지는 단계

표는 기존 2022·2024 개발 감사의 고정 예측을 다시 읽은 결과다. 새 모델/임계값 선정이나 새 미사용 검증이 아니다.

| 확인 항목 | 2022 감사 | 2024 감사 |
|---|---:|---:|
| 평가 표본 | 487,276 | 588,175 |
| 실제 성공 표본 | 144,417 (29.64%) | 166,693 (28.34%) |
| 선택 앙상블 보정 전 최대 성공확률 | 43.03% | 44.13% |
| 확률 보정 후 최대 | 43.89% | 45.10% |
| p>50% 표본 | 0 | 0 |
| 추가 선별 조건이 제거한 신호 | 0 | 0 |
| 가장 높은 확률 상위 1%의 실제 성공률 | 38.05% (4,873개) | 40.41% (5,882개) |
| 상위 0.1%의 실제 성공률 | 40.98% (488개) | 44.14% (589개) |

현재 정답은 `당일 고가 ≥ 시가×1.01 AND 당일 저가 > 시가×0.991`이다. 사용자가 정한 대로 두 경계를 모두 건드리면 실패다. 2024년에는 +1%에 닿은 표본이 304,733개지만, 그중 138,040개는 손절 경계도 건드려 성공으로 세지 않는다. 상승 종목이 많다는 사실과 진입 전에 성공확률 50% 초과를 식별할 수 있다는 것은 다른 문제다. 이 정답을 임의로 완화하지 않았다.

2024년 상위 1%의 평균 예측확률은 40.35%, 실제 성공률은 40.41%였다. 이 부분의 확률이 단순히 눌린 것은 아니다. 확률 문턱을 내리거나 클래스 가중치로 숫자만 키워도 이 관측 성공률 자체가 높아지지는 않는다.

## 실제로 발견한 데이터 문제

### 분할·병합 경계가 정상 30봉으로 연결됨

아래 가격은 로컬 DB/학습 캐시의 값이다. 실제 체결 가격을 독립 검증해 복원한 값이 아니다.

| 종목/경계 | 현재 저장 값 | 문제 |
|---|---|---|
| FCEL, 2024-11-08→11→12 | 종가 7.503 → 11일 시가 202.5·종가 200.4 → 12일 시가 6.45 | 30:1 병합 경계에서 가격 단위가 튀었다가 복귀한다. 조정 표시는 12일에 있고 같은 학습 구간에 남아 있다. |
| BNED, 2024-06-11→12 | 종가 0.0943 → 다음 시가 7.05 | 약 74.76배의 가짜 수익률 성분을 포함할 수 있는 미연결 조정 경계다. 단순한 7,000% 급등 학습 자료로 사용할 수 없다. |
| BBSI, 2024-06-21→24 | 종가 135.27 → 다음 시가 33.96 | 4:1 분할의 약 1/4 가격 변화가 수익률 변화로 입력된다. |

FCEL은 2024-11-11부터 30:1 병합 조정 거래가 시작된다고 [Nasdaq 공식 기업행사 공지](https://www.nasdaqtrader.com/TraderNews.aspx?id=ECA2024-540)에 나온다. BNED는 2024-06-12부터 100:1 병합 조정 거래를 시작한다고 [회사 SEC 공시](https://www.sec.gov/Archives/edgar/data/1634117/000119312524159120/d818124dex991.htm)에 나온다. BBSI의 2024-06-24 4:1 분할 조정 거래는 [회사 발표](https://ir.bbsi.com/news-events/press-releases/detail/373/bbsi-declares-four-for-one-stock-split)로 확인했다. 이 공시들은 행사 비율/일정을 뒷받침하며, 로컬 OHLC의 정확한 교정값을 제공하는 것은 아니다.

SONY의 2024-09-27 종가 3.8464→09-30 시가 19.38도 조사 대상이다. 일본 보통주와 미국 ADR의 기업행사 날짜를 혼동하면 안 된다. Sony 공시는 일본 보통주 효력일을 10월1일, ADR 효력일을 10월8일로 구분한다. [Sony SEC 공시](https://www.sec.gov/Archives/edgar/data/313838/000110465924060803/tm2414258d1_6k.htm)

정제 v1은 큰 등락을 확정 오류로 일괄 삭제하지 않고 `ABS_RETURN_GE_50PCT` 등의 표식만 남겼다. 실제 급락/급등을 정답을 보고 제거하지 않으려는 규칙이지만, **기업행사로 인한 가격 기준 불연속을 별도로 처리하지 못했다.** 이 구간이 과거 입력에 들어가면 가짜 수익률·변동성·갭·추세를 학습한다. 하루 OHLC 네 값이 같은 배수로 틀린 경우 당일 비율 라벨은 그대로일 수 있어, 라벨 검사만으로는 잡히지 않는다.

공식 행사와 대조한 불연속 경계 하나는 승인 창30개에 노출된다(해당일 가격 질의 + 이후29개 과거 입력 창). FCEL은11일 급증과12일 복귀의 노출 창이 겹쳐 합집합31개, BNED와BBSI는 각각30개로 세 사건군의 영향 창은91개다. 같은 봉을 공유하는 창이므로 독립 오류91건이라고 세지 않는다.

영향 후보를 놓치지 않기 위한 넓은 스크린도 계산했다. 과거 입력 29개 가격 변화 또는 현재 시가 갭이 1.5배 이상/1÷1.5 이하인 창은 최종 학습150만 개 중6,610개(0.4407%), 정확한2024 감사588,175개 중3,232개(0.5495%)였다. 2배 이상/절반 이하로 좁히면 각각2,273개/1,063개다. **실제 기업 악재·정상 급등락도 포함하므로 이 수치는 오류 개수가 아니며 전부 삭제하라는 뜻도 아니다.** 확정 사례는 교정하고 나머지는 기업행사/독립 원천으로 재검토해야 한다.

### 사용하지 않는 등락액 필드도 조정 기준이 다름

- AAPL 2020-08-25: 조정 종가 차이는 −1.0325인데 저장 `change`는 −4.13.
- NVDA 2024-06-04: 조정 종가 차이는 +1.437인데 저장 `change`는 +14.37.
- 현재 모델은 저장 `change`/`change_rate`를 입력하지 않고 OHLC로 수익률을 다시 계산한다. 따라서 이 필드 불일치는 실제 주의사항이지만 현재 무신호의 직접 원인으로 볼 수 없다.

### 정상으로 확인한 범위와 확인하지 못한 범위

- 원본 미국 일봉 26,100,170행에서 OHLC 범위 위반 30,556행을 확인했다. 정제 12,145,737행에는 같은 범위 위반, 비양수 가격, 음수/누락 거래량, 비USD 통화가 없었다. 거래량0인 과거 봉295행은 유지되어 있다.
- 무작위·양성/음성·극단값·대표 종목을 포함한 592개 승인 창, 18,352개 봉을 원본→정제→캐시와 대조해 복사/정렬/31봉 대응 불일치를 찾지 못했다. **원본 자체의 잘못된 값을 일관되게 복사한 경우까지 정상이라는 뜻은 아니다.**
- NVDA/AAPL/TSLA의 대표 분할 구간에는 OHLCV가 연속적인 사례도 있었다. 일부 대표 종목이 정상이라고 다른 종목의 모든 기업행사가 정상인 것은 아니다.
- 미국 두 개발 구간의 학습/감사 특징 행렬 184열을 전수 검사했다. 비유한 값 0개, 전체가 상수인 특징 0개였다. 제한값에 걸린 특징 값은 약 0.0016~0.0030%로, 전처리가 모든 값을 같은 값으로 만든 문제는 아니다.
- 두 개발 구간에서64개씩 고른128행의184개 특징을 다시 생성해 저장된 특징과 비트 단위 일치, 각 시간 구간의 표본 색인 체크섬 일치를 확인했다. 위592창과 중복될 수 있어 검사 수를 합산하지 않는다.
- 원본 DB에는 봉별 원래 HTTP 응답이 보존되지 않았다. 따라서 공급자 원응답/파싱/조정 시점의 어느 단계에서 가격 불연속이 생겼는지는 아직 분리 확정하지 못했다. 수정값을 추측해 DB에 곱하거나 나누지 않았다.

## 학습·모델 선정에서 확인한 점

미국 네 후보 모두 두 감사 연도에서 요구한 신호 증거 기준을 충족하지 못했다. 그래서 `architecture_ranking()`의 진단용 Brier 예비 순위로 `cat_binary8`이 남았다. 이 모델을 학습 성공 또는 실전 후보라고 표현해서는 안 된다.

신호가 나온 joint 모델도 대안으로 검증된 것은 아니다. 2022년 92신호의 성공률 34.78%, 2024년 3신호의 성공률 33.33%였다. 단지 무신호를 피하려고 이 모델로 바꾸면 안 된다.

조기 종료의 저장 iteration과 전체 종료 지표 곡선의 최고 지점은 12개 미국 실험 모두 일치했다. 선택된 모델들의 최적 iteration은 78~165이며, 별도 탈락 후보에만 8회짜리 모델이 있었다. 모델 파일이 비었거나 그 8회짜리 모델이 잘못 선택된 것은 아니다. 다만 전체 Logloss/PR-AUC와 드문 BUY의 높은 정밀도는 같은 최적화 목표가 아니므로 후속 실험 설계에는 개선 여지가 있다. [CatBoost 지표 정의](https://catboost.ai/docs/en/concepts/loss-functions-classification)

## 성공률 개선을 위해 우선할 작업

| 우선순위 | 제안 | 이유·검증 방법 |
|---|---|---|
| 1 | 기업행사·종목 신원·가격 기준을 교정한 데이터 v2 | 공식 행사/독립 시세로 확인된 값만 고치고 불확실 구간은 별도 격리한다. 큰 정답 수익률만 보고 삭제하지 않는다. 원본 보존, 승인 30봉 재생성 후 같은 구조를 먼저 재학습해 데이터 수정 효과를 분리한다. |
| 2 | 합격 BUY 모델 없음과 진단용 모델 순위를 분리 | Brier 1위로 무신호 모델이 남아도 배포 가능한 선정 모델로 보이지 않게 한다. 거래를 강제로 만들지 않고 충분한 비영 신호·날짜·종목에서 정밀도와 비용 후 기대값을 검증한다. |
| 3 | BUY에 한정한 정밀도/선별 위험 목표 비교 | 전체 정답률이나 전체 확률 오차만이 아니라 채택한 BUY의 오류를 학습/검증 목표로 비교한다. 별도 시간의 확률 보정·정책 선택·감사를 유지한다. [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)은 참고 아이디어이지 이 거래 문제의 효과 보장이 아니다. |
| 4 | 시장·섹터 정보와 국면별 모델 비교 | 현재 184개 특징은 개별 종목 30봉과 시가에 한정된다. 당시 알 수 있던 시장/섹터 추세, 상대 강도, 사전 알려진 이벤트를 추가하는 실험이 층 수만 늘리는 것보다 검토 가치가 있다. [TRA 논문](https://arxiv.org/abs/2106.12950)은 주식 순위 예측 연구로, 현재 장벽 목표에 대한 검증은 별도로 해야 한다. |
| 5 | 임의 장중 진입이 목적이면 분봉 경로 추가 | 시가 기준 하루 전체 라벨로 장중 특정 가격 이후의 잔여 경로를 검증할 수 없다. 추가 수집은 아직 하지 않았으며 현재 +1%/−0.9%·양쪽 도달 손절 우선 규칙을 임의로 바꾸지 않는다. |

단순히 저변동성만 남기는 것도 검증된 해결책은 아니다. 사전 고정한 과거 변동성 구간을 모든 개발 기간에 비교한 결과, 2024년 변동성<1% 그룹은 미도달이 53.66%였고, 변동성≥5% 그룹은 양쪽 경계 도달 실패가 60.82%였다. 1~2% 그룹의 성공률도 32.75%였다. 2022년에도 같은 방향이며 비교한 모든 고정 구간의 비용20bp 후 일봉 수익 대용치는 음수였다. 이 특징은 이미 모델에 포함되어 있어 국면별 모델이 실제로 더 나아질지는 새 실험으로 확인해야 한다.

**결론: 데이터 보완이 먼저이고, 그 다음은 BUY 목적에 맞는 학습·선정과 추가 정보의 비교다. 더 오래 학습하거나 문턱을 낮추는 것만으로 해결됐다고 볼 근거는 없다.**
