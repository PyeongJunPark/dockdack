# Mark_1 심화 모델 비교: 사전 고정 실험 계획

이 문서는 **실험 조건과 판정 기준**이다. 학습 완료, 성능 향상, 수익성 입증을 보고하는 결과 문서가 아니다. 실제 결과는 실행 산출물과 별도의 결과 보고서로 확인한다.

기준 구현은 `examples/train_mark1_deep.py`, `dockdack/mark1_deep_data.py`, `dockdack/mark1_deep_models.py`, `dockdack/mark1_deep_validation.py`이다. 실행 시 설정과 코드 파일의 SHA-256을 기록한다. 이미 시작한 실험의 조건이나 코드가 바뀌면 같은 출력 폴더로 이어서 실행하지 못하도록 막는다.

## 유지하는 사용자 조건

- 입력은 **과거 30개 완료 일봉 + 당일 가상 매수가**다. 31번째 입력은 완성된 당일 봉이 아니다.
- 성공 정답은 당일 고가가 가상 매수가 대비 +1% 이상이고 당일 저가가 −0.9% 손절선보다 높은 경우다.
- 같은 날 두 가격을 모두 찍으면 **손절이 먼저였다고 처리**한다.
- 매수 조건의 확률 경계는 **50% 초과**다. 정확히 50%면 매수 신호가 아니다.
- 매도 목표는 실제 매수가 대비 **+1% 익절 / −0.9% 손절**을 유지한다.
- 이번 작업은 연구용 학습·검증이다. 기존 GUI의 주문 설정, 배포 체크포인트, 자동매매 ON/OFF를 바꾸지 않으며 주문을 제출하지 않는다.

학습 성공은 당일 **전체** 고저가로 정의한다. 일봉에는 실제 장중 진입 시각과 이후 가격 경로가 없으므로, 가상 매수가를 바꿨을 때도 그 가격에 실제 진입할 수 있었는지, 관측된 고저가가 진입 후였는지는 알 수 없다. 네 가지 결과를 분류하거나 신경망을 깊게 만들어도 이 한계가 사라지지는 않는다.

## 1. 데이터와 시간 분리

국내·미국은 각각의 로컬 정제 DB를 읽기 전용으로 사용한다. 기존 승인 `training_samples`가 가리키는 연속 30+1 거래일만 대상으로 하며, 원본·정제 DB는 수정하지 않는다. 기존 `target_up` 정답을 재사용하지 않고 가상 매수가 기준 장벽 정답을 새로 계산한다.

| 구간 | 모델 가중치 학습 | 학습 종료 시점 결정 | 확률 보정 | 구조 비교·선택 |
|---|---|---|---|---|
| `walk_2022` | 2012–2019 | 2020 | 2021 | 2022 |
| `walk_2024` | 2014–2021 | 2022 | 2023 | 2024 |

표의 연도는 목표일 기준이다. 학습 시작일 직전 과거 문맥은 사용할 수 있지만 미래 정보는 쓰지 않는다. 학습 이후 각 구간에서는 **과거 30봉의 첫 날짜까지 해당 연도에 들어오는 표본만** 허용한다. 즉 각 연도의 첫 30개 목표 거래일을 제거해, 이전 구간과 입력 창이 겹치지 않게 한다. 주말을 포함한 30일이 아니라 DB의 거래소 달력 기준 30거래일이다.

각 시장·구간의 종목군은 해당 학습 기간에 승인 표본이 있는 종목만으로 고정한다. 종목군을 먼저 결정한 다음 표본 수를 제한한다. 이후 연도에서만 등장한 종목을 보고 과거 학습 종목군을 바꾸지 않는다.

- 학습: 최대 **750,000개 기본 관측치**, 균등 추출·고정 seed 42.
- 학습 종료 검증: 최대 **100,000개**, 동일하게 정답을 보지 않는 균등 추출.
- 확률 보정과 선택: 조건을 만족하는 승인 표본 **전부** 사용하며 별도 수량 제한을 두지 않는다.
- 실제 표본 수·종목 수·날짜 범위는 각 실행의 `split_manifest.json`에 기록한다.
- 가격을 바꾼 예시는 같은 관측치의 질의 변형이지 새로운 독립 시장 관측치가 아니다.
- **2025년 이후는 이 학습 실행기의 학습·보정·선택에서 제외**한다.

두 구간은 별개의 독립 실험 표본이 아니다. 예를 들어 2022년은 첫 구간의 구조 선택에, 두 번째 구간의 학습 종료 검증에 사용된다. 과거에 이미 확인한 2025년 이후 결과를 다시 비교하더라도 반드시 **재사용한 역사 평가**라고 표시하며 새 미관측 테스트라고 부르지 않는다.

## 2. 과거 정보만으로 만드는 18개 특징

입력 배열은 `[표본 수, 31, 18]`이다. 모든 통계는 각 표본의 과거 30개 완료 봉에서만 계산한다. 당일 고가·저가·종가·전체 거래량은 특징에 들어가지 않는다.

| 채널 | 의미 |
|---|---|
| 1–4 | 마지막 과거 종가 대비 OHLC 로그 위치를 과거 변동성으로 나눈 값. 질의 토큰에서는 1번만 가상 매수가 위치를 담음 |
| 5 | 과거 30일 `log(1+거래량)`의 평균을 빼고 표준편차로 나눈 상대 거래량 |
| 6–7 | 변동성으로 나눈 종가 로그 수익률, 고저 로그 범위 |
| 8–11 | 봉 범위 대비 몸통, 종가 위치, 위꼬리, 아래꼬리 |
| 12–13 | 로그 가격 수준을 10으로 나눈 값, 로그 거래량 수준을 20으로 나눈 값 |
| 14–15 | 과거 변동성의 로그 수준과 변동성 대비 과거 평균 수익률 |
| 16 | 직전 종가 대비 과거 시가 갭을 변동성으로 나눈 값 |
| 17–18 | 과거 봉인지, 가상 매수가 질의인지 구별하는 마스크 |

변동성은 과거 29개 종가 로그 수익률의 모집단 표준편차이며 `[0.003, 0.3]` 범위로 제한한다. 상대 거래량의 로그 표준편차 분모에는 최솟값 1을 둔다. 모든 채널은 미리 정한 `[-12, 12]` 범위로 제한한다. 전체 데이터나 미래 구간에서 평균·표준편차를 학습하지 않는다.

질의 토큰에는 가상 매수가 위치·가격 수준, 과거에서 얻은 변동성·추세, 질의 마스크만 들어간다. 가격 정보가 없는 다른 당일 채널은 0이다. 고저 차이가 0인 과거 봉은 몸통·꼬리를 0, 종가 위치를 중립 0으로 처리한다.

## 3. 비교할 네 구조

모든 구조는 특징 18개, 총 입력 길이 31, 기본 폭 `width=32`, dropout 0.2를 사용한다. 과거 30봉과 가상 매수가 질의는 **서로 다른 인코더**로 처리한 뒤 합친다. 질의를 실제 완성 봉처럼 합성곱에 넣지 않는다.

| 구조 | 비교 목적과 구현 | 실제 학습 파라미터 수 |
|---|---|---:|
| Deep MLP | 과거 입력을 펼쳐 4개 은닉층으로 처리하는 강한 기본 비교군 | 215,684 |
| 1D ResNet-18 계열 | 잔차 블록 수 `[2,2,2,2]`, 시간축 합성곱으로 깊은 특징 학습 | 1,040,708 |
| 1D ResNet-34 계열 | 같은 계열에서 블록 수를 `[3,4,6,3]`으로 늘려 깊이 효과 비교 | 1,886,148 |
| Inception 계열 | 커널 3·7·15와 pooling 경로를 병렬로 사용, 총 6개 다중 크기 모듈 | 259,396 |

표의 수는 기본 봉 수나 증강 표본 수가 아니라 학습으로 조정되는 가중치 수다. ResNet은 잔차 학습의 아이디어를 1차원 시계열에 적용했다. 원 논문의 이미지 인식 결과가 주식 예측의 개선을 보장하는 것은 아니다. [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)

Inception 구현은 여러 크기의 시간 패턴을 함께 처리하는 시계열 분류 계열을 참고했다. 단, 30일 입력에 맞춰 커널을 줄였으며 정규화·활성화·질의 결합 방식도 달라 **InceptionTime 원 논문의 동일 재현은 아니다**. [InceptionTime: Finding AlexNet for Time Series Classification](https://arxiv.org/abs/1909.04939)

ResNet의 GroupNorm·GELU·평균/최대 pooling·가격 질의 헤드 또한 이 실험의 구현 선택이다. 이번 새 모델과 이전 MLP 사이에는 깊이뿐 아니라 특징, 손실, 데이터 수, 학습 예산이 함께 바뀌므로 **깊이만의 통제 비교라고 해석하지 않는다**. 이번 ResNet-18 계열과 ResNet-34 계열 비교가 더 직접적인 깊이 비교에 해당한다.

## 4. 네 가지 정답과 제한적인 가격 증강

각 입력의 네 출력은 다음을 뜻한다.

| 출력 | 당일 결과 | 매수 성공 정답 |
|---|---|---|
| 0: `take_only` | 익절선만 도달 | 1 |
| 1: `stop_only` | 손절선만 도달 | 0 |
| 2: `both_touch` | 둘 다 도달 | 0 — 손절 우선 |
| 3: `neither` | 둘 다 미도달 | 0 |

성공 logit은 첫 출력에서 나머지 세 출력의 `logsumexp`를 뺀 값이다. 그 sigmoid는 네 클래스 softmax 중 `take_only`의 확률과 같다. 이후 독립 보정 연도로 이 성공 확률을 보정한다. 수치 반올림으로 정확한 경계 접촉이 사라지지 않도록 기존의 보수적인 상대 허용오차 `1e-12`를 유지한다.

학습 손실을 사전에 다음으로 고정한다.

`실제 시가 성공/실패 BCE + 0.25 × 실제 시가 4클래스 CE + 0.10 × 증강 가격 성공/실패 BCE`

클래스 가중치나 양성 오버샘플링으로 성공 빈도를 인위적으로 바꾸지 않는다. 기본 관측치마다 매 epoch 실제 시가 예시 1개와 변형 가격 예시 1개를 제시한다. 변형 가격은 다음 네 배수 중 균등하게 하나를 고른다.

- 시가의 `0.995`, `0.9975`, `1.0025`, `1.005`배, 즉 **−0.5%, −0.25%, +0.25%, +0.5%**.
- 실제 시가 `1.0`배가 주 학습 대상이다.
- 학습 종료 검증·확률 보정·구조 선택은 **실제 시가만** 사용한다.
- 미래 당일 고저 범위로 가상 매수가를 걸러내지 않는다. 그러한 필터는 미래 정보 선택이 될 수 있다.

이전의 ±1% 증강은 일부 정답을 기계적으로 고정시키므로 이번에는 범위와 손실 가중치를 줄였다. 그렇더라도 가상 가격에 실제 체결될 수 있었음을 입증하는 방법은 아니다.

## 5. 학습 예산과 앙상블

- 각 구조·시장·시간 구간은 seed **42**로 먼저 비교한다.
- 최대 **40 epoch**, 최소 **10 epoch**, 개선 없는 검증 횟수 **8**의 조기 종료를 사용한다.
- 가장 좋은 epoch는 실제 시가 기준 검증 연도의 **보정 전 성공/실패 BCE**로 선택한다. 최소 개선 폭은 `1e-5`다.
- AdamW, 기준 학습률 `0.0003`, weight decay `0.001`, 기본 관측치 배치 크기 **1,024**, gradient norm 상한 **1.0**.
- 처음 **3 epoch warm-up**, 이후 cosine 스케줄로 기준 학습률의 10%까지 감소한다.
- CUDA에서는 BF16 혼합 정밀도를 사용하되 성공 logit·손실 등은 float32로 계산한다.
- 학습 상태·최적 가중치·난수 상태·이력을 저장해 같은 동결 조건으로 이어갈 수 있게 한다.

먼저 네 구조를 두 시간 구간에서 비교해 시장별 구조를 하나 선택한다. 그 후 해당 구조의 `walk_2024`를 seed **43, 44**로 추가 학습한다. seed 42를 포함한 **세 모델의 보정 전 성공 logit을 평균**하고, 그 평균값에 **2023년 자료로 양의 기울기 Platt 보정**을 다시 적용한다. 이미 보정된 확률들을 단순 평균하는 방식이 아니다.

학습 난수 seed는 달라져도 표본 추출 seed와 각 시간 분할은 동일하다. 세 모델을 합쳐도 독립된 시장 자료를 세 배 확보한 것은 아니다.

## 6. 구조 선택 기준

각 시간 구간의 선택 연도에서 Brier 점수를 계산한다. 상수 비교군은 **그 구간의 확률 보정 연도 성공 비율**을 모든 표본의 예측 확률로 사용한다. 선택 연도의 정답 비율로 상수 확률을 미리 맞추지 않는다.

`구간별 Brier skill = 1 − 모델의 선택 Brier / 상수 비교군의 선택 Brier`

두 구간의 Brier skill을 동일 비중으로 평균해 가장 높은 구조를 고른다. 동점이면 구조 이름 순서로 결정한다. 상수보다 좋아야 skill이 양수지만, 네 구조가 전부 좋지 않더라도 순위상 1위는 존재할 수 있다. **순위 1위와 연구 기준 통과는 별개**다. 구조를 고른 기록은 추가 두 seed 학습 이전에 고정한다.

## 7. 매수 확률의 신뢰도와 연구 통과 기준

점수는 실제 시가 기준이고 신호는 보정 확률 **0.5 초과**다. 신호별 수익은 일봉으로 계산한 동일 가중의 당일 근사 수익이다.

- 손절선 접촉 또는 둘 다 접촉: −0.9%.
- 손절선 없이 익절선 접촉: +1%.
- 둘 다 미접촉: 당일 종가/가상 매수가 − 1.
- 모든 신호에서 왕복 비용 **20bp = 0.2%** 차감.

미도달 종가 청산은 연구 평가의 시간 종료 가정이지 기존 GUI 매도 설정을 바꾼다는 뜻이 아니다. 이 수익은 거래량·호가·동시 보유 수·자금 한도·매수 가능 수량을 포함한 포트폴리오 백테스트가 아니며 체결 수익도 아니다.

날짜별로 같은 날 종목들을 함께 묶고, 평가 자료에 존재하는 **연속 10개 거래일 그룹**을 블록으로 재추출한다. 신호가 없는 평가 날짜도 유지한다. seed 42, **500회**, 비순환 moving-block percentile 방식의 **95% 구간**을 사용한다. 이는 같은 날 종목 상관과 일부 시계열 의존을 반영하지만 모든 의존성이나 여러 모델을 탐색한 불확실성까지 제거하지 않는다. 제공 자료에 없는 거래일은 별도 달력 없이 복원하지 못한다.

구간 자체는 신호 100개 또는 신호 발생일 30일 미만이면 계산하지 않는다. 더 엄격한 최종 연구 기준은 다음을 **모두** 요구한다.

1. 매수 신호 **200개 이상**.
2. 서로 다른 신호 발생일 **50일 이상**.
3. 성공률 95% 구간의 **하한이 50% 초과**.
4. 왕복 비용 0.2% 차감 후 평균 근사 수익의 95% 구간 **하한이 0 초과**.
5. 비용·블록 길이·횟수·seed·구간 메타데이터가 동결 규칙과 일치하며 누락·비정상 값이 없음.

선정 구조의 seed 42 모델이 **두 개발 시간 구간 모두**에서 이 기준을 통과해야 하며, 최종 3-seed 앙상블도 `walk_2024`에서 통과해야 연구 기준 통과로 표시한다. 표본이 적거나 확률 구간이 없으면 통과시키지 않는다. 기준 통과도 실제 주문 허가나 미래 수익 보장은 아니다.

참고로 모든 거래가 정확히 +1% 또는 −0.9%로만 끝나고 왕복 비용이 0.2%라는 단순한 경우, 기대수익은 `0.01p − 0.009(1−p) − 0.002`다. 손익분기 성공률은 `0.011 / 0.019 ≈ 57.9%`이므로 **성공 확률 50% 초과만으로 비용 후 수익이 양수인 것은 아니다**. 실제 평가는 미도달 종가 청산도 포함하고, 현실의 갭·체결 비용은 이 단순식보다 더 불리할 수 있다. 사용자 매수 임계값은 50%로 유지하며 연구 통과에는 비용 후 기준을 별도로 적용한다.

## 결과 해석과 배포 경계

이번 목표는 더 큰 모델을 오래 학습하는 동시에 특징 스케일·가격 증강의 왜곡·확률 보정·시간별 안정성을 검증하는 것이다. 개선은 실제 산출물로 확인해야 하며, 층이 깊다는 이유로 먼저 성공을 선언하지 않는다.

현재 종목 카탈로그의 생존 편향, 정제 및 승인 표본 선택, 일봉 내 시간 순서, 실제 장중 진입 시점, 가격 조정의 일관성, 스프레드·슬리피지·유동성·갭 손실은 남는다. 2024년까지의 개발 자료도 이전 실험과 진단에 사용한 이력이 있다. 따라서 이 문서의 판정은 **개발 단계의 비교 기준**이지 완전히 새로운 독립 검증을 대신하지 않는다.

산출물은 기본적으로 `outputs/mark1/deep-20260916/` 아래에 저장한다. 이 실행기는 기존 `models/mark1/` 모델을 자동으로 덮어쓰거나 GUI에 승격하지 않는다. 이번 작업에서 자동매매를 켜거나 주문하지 않고, 커밋·푸시도 자동 수행하지 않는다.

## 실행과 연구용 추론

`dockdack-mark_1` 작업 폴더에서 CUDA 지원 PyTorch가 설치된 Python으로 실행한다.

```powershell
python -m examples.train_mark1_deep
# 국내·미국 학습과 앙상블이 모두 완료된 다음에만 실행 가능
python -m examples.backtest_mark1_deep --device cuda
python -m examples.report_mark1_deep
```

동일 코드·조건에서는 완료 실험을 재사용하고 진행 중 실험은 `resume.pt`에서 이어간다. 코드나 조건이 달라지면 기존 실행에 덮어쓰지 않고 새 출력 디렉터리를 지정해야 한다. 평가 출력은 기존 디렉터리를 덮어쓰지 않는다. seed는 고정하지만 모든 GPU 환경에서 비트 단위 일치를 보장하는 설정은 아니다.

학습 완료 후 별도 프로그램에서 확률만 읽는 예:

```python
from dockdack.mark1_deep_inference import DeepPredictor

predictor = DeepPredictor("outputs/mark1/deep-20260916/domestic", device="cpu")
# history: 과거 완료된 30봉, 오래된 순, 각 행 [시가, 고가, 저가, 종가, 거래량]
result = predictor.predict(history, current_price)
print(result["probability_success"], result["predicts_success"])
```

미국은 마지막 경로를 `us`로 바꾼다. 모듈은 주문하지 않으며 항상 `research_only=True`, `deployment_allowed=False`를 반환한다. `research_qualified`도 실제 주문 승인이 아니다. 기존 GUI는 이 모듈을 자동으로 불러오지 않는다.

CPU 추론은 FP32, 이번 GPU 평가 경로는 BF16이다. 두 경로의 확률에는 작은 수치 차이가 있을 수 있고 50% 경계 부근에서는 신호가 달라질 수 있다. 실제 배포 전에 배포할 정밀도·실행환경으로 확률 보정과 경계 검증을 다시 해야 한다.
